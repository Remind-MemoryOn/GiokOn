브라우저는 종료/명시적 이동 전 카운터를 수집하고 snapshot/reset을 같은 JS 호출에서 수행한다. 비어 있지 않은 실행 카운터를 확인하며 수집 오류·이동 중 손실을 별도 기록한다. **앱이 시작한 문서 이동은 스냅샷 전에 일부 카운터를 잃을 수 있어 브라우저 수치는 보수적 하한**이다. 실제 OAuth 제공자 인증은 합성 응답으로 대체돼 있다.

## 남은 검증과 해석

- **모바일 UI/네이티브:** 여러 화면·컴포넌트·인증 호스트·데이터 어댑터가 미도달이다. 실제 Kotlin/Swift AEC·마이크·오디오 포커스·재생 완료·잠금/백그라운드·OS 권한은 이번 JS 실행으로 검증하지 않았다. 네이티브 구현을 읽어 경계를 점검했지만 이번에 컴파일/실행한 것으로 보고하지 않는다.
- **data/React 훅:** 단위 지표는 낮다. 브라우저가 일부 훅을 실제 실행한 별도 수치를 제공하지만, 모든 쿼리·mutation·Realtime·오류 조합을 전수 검증하지 않았다. 미도달 파일/분기는 커버리지 HTML과 JSON에 남아 있다.
- **중계:** `main.ts` 자식 프로세스의 시작/health/readiness/종료 시험은 통과했으나 그 자식은 Istanbul 계측 밖이라 0%로 분모에 남겼다. backpressure, 비정상 envelope/예산, provider barrier timeout, 취소 후 콜백, 특이 SSE/WAV 형식 등 일부 분기 미도달이다.
- **core/Edge:** 관찰·날짜·표시 헬퍼, 공급자 데이터 형태·옵션 기본값·일부 재시도/오류 분기가 미도달이다. 실제 Deno 런타임, 운영 권한/시크릿/cron/워커 HTTP 설정, Gemini 품질·지연은 시험 더블로 대체됐다.
- **전 경로/조건:** 전체 MC/DC, 무한 경로, 스케줄 전수, SQL·네이티브 수치 커버리지는 달성하지 않았다. 안전 문장 정규식 통과가 사실·의학적 정확성 보장은 아니다.
- **실환경:** 실계정 OAuth·메일, 실제 앱/Cloud Run/DB/워커/Expo/FCM/APNs/OS를 잇는 종단, 지원 기기/화면·음성 품질은 다음 실기기 회차에서 실행한다. 운영 DB 쓰기·배포·AI 스위치 변경은 이번 작업에서 수행하지 않았다.

## 재실행 — Windows cmd

저장소 루트, 이미 설치된 프로젝트 의존성·Node 22.15 이상(이번 실행 Node 24.16.0), 브라우저가 필요하다. 추가 계측 도구는 저장소 밖 TEMP에 둔다. 기존 package.json·pnpm-lock는 바꾸지 않았다.

```cmd
set "WHITEBOX_TOOLS_DIR=%TEMP%\memoryon-whitebox-tools-20261025"
npm install --prefix "%WHITEBOX_TOOLS_DIR%" --no-audit --no-fund vitest@3.2.6 @vitest/coverage-istanbul@3.2.6 istanbul-lib-instrument@6.0.3 istanbul-lib-coverage@3.2.2 istanbul-lib-report@3.0.1 istanbul-reports@3.2.0 typescript@6.0.2
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\test-whitebox.ps1 -Browser
node scripts\whitebox-summary.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\test-blackbox-db.ps1
node --test scripts\check-audit.test.mjs
pnpm -r typecheck
pnpm -r lint
pnpm check:bom
```

`test-whitebox.ps1`은 5영역을 직렬 실행하고 중계의 자식 프로세스 cwd를 맞춘다. 브라우저 16개도 순차 실행한다. 모든 Vite 계측은 `envDir:false`, 실제 공급자/DB HTTP는 합성 응답이다. DB 러너는 Docker Desktop/PostgreSQL16 이미지가 필요하며 `--network none`·tmpfs·회차별 임시 컨테이너를 사용한다.

기본 상세 보고서는 `.tmp/whitebox/<영역>/coverage/index.html`, 원본 TS 브라우저 보고서는 `.tmp/whitebox-2026-10-25/summary/{webBrowser,dataBrowser}/index.html`이다. 원시 로그·시험용 변형은 `.tmp/whitebox-2026-10-25`에 보존하고 핵심 요약/단언 결과는 저장소 증거 폴더에 남겼다. 초기 도구 진단 실패(VM 계측 분리, 중계 cwd, 브라우저 설치 경로, 차트 SSR 래퍼)는 최종 통과 기록과 구분했다.
