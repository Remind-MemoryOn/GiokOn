# 재생성 일지 저장·내용·작성 부담 점검

점검일: 2026-10-26. 운영 DB 읽기, 해당 세션 전사와 현재 일지 대조, 웹·워커·DB 가드 코드 검토. 사용자 재실행 뒤 확인했으며 브라우저 화면 직접 검증은 아니다. 원문과 개인 식별자는 문서에 복제하지 않는다.

## 결과

실제 생성·저장은 성공했다. 모든 필드가 완성됐거나 내용이 완전히 정확하다는 판정은 아니다. 사용자 요구인 추가 작성·수정 부담 최소화는 부분 반영이다.

| 항목 | 관측값(KST) |
|---|---|
| 원래 일지 생성 | 2026-10-17 16:03:49 |
| 재실행 워커 202 접수 | 2026-10-26 22:06:53.504 |
| AI 초안 저장 | 2026-10-26 22:06:57.664 |
| 확정 | 2026-10-26 22:11:03.686 |
| 현재 상태 | final / 작업 done |
| 재실행 시도 / 오류 | 1회 / last_error null |
| 보호자 문장 승인 / 공개 | 미승인 / 공개 행 0건 |
| 확정 뒤 수정 이력 | 0건 |

접수 로그부터 DB 저장까지 약 4.16초다. 버튼 클릭부터의 총시간·순수 모델 추론 시간은 계측하지 않았다. 운영 finish 함수가 pending_review를 기록하는 계약을 확인했고 현재 final로 전환돼 있다. pending_review 당시 화면을 직접 관측한 것은 아니다. finalized_by가 있는 사람 계정 확정이며 실제로 본문을 읽었는지까지 증명하지 않는다. 이 일지의 product_events 조회 결과는 0행이어서 이벤트로 별도 확인 이력을 재구성하지 않았다.

현재 전체 일지는 final 1건, failed 7건(기존 생성 단계 실패6 + 발화 없음1)이다. 다른 일지의 복구 성공은 확인하지 않았다. 과거 실패의 원인은 상세 오류가 없으므로 이번 성공만으로 소급 확정할 수 없다. 진단 패치는 관측성 수정이며 모델 변경이나 공급자 장애를 고친 패치가 아니다.

## 추가 작성·수정 부담 평가

사용자가 제시한 '추가 작성·수정을 기피하는 사용 맥락'을 기준으로 평가한다. 요양보호사 전체에 대한 실증 조사 결과는 아니다.

- 자동 반영: 일자·시간·유형·진행자·도구 + 생성된 진행 내용·참여자 반응·보호자 문장.
- 수동 부담: 장소·참여자·목표·의견수렴·평가·다음 계획 6칸이 비어 있다. 일부는 근거 부재/사람 판단 영역이므로 단순 자동 생성으로 채우면 안 된다.
- 웹은 긴 textarea와 'AI가 채우지 않은 칸이에요. 직접 적어 주세요.' 안내를 사용한다. 근거 없음·해당 없음·사람 판단 필요를 구별하지 않는다.
- 초안 내용을 수정하지 않고 확정하는 것은 가능하다. 현재 확정 가드는 진행자와 제공 시 진행 내용을 핵심 필수로 검사한다. 나머지 빈 칸이 있어도 확정 가능하다. 실제 이번 일지가 그 상태로 확정됐다.
- 자동 작성 정보의 근거를 문장 옆에서 보여 주는 흐름이 없어, 정확성 확인을 위해 원래 대화를 별도로 찾아야 한다.
- '확정됨'은 필드 완전성이나 공단 서식 적합성을 인증하는 상태가 아니다. 법적 필수 항목에 대한 판정은 이 점검 범위에 포함하지 않는다.

## 개선 우선순위(미구현)

1. **사실 정확성:** 사람·행동 관계를 보존하고 방문과 연락을 합치지 않도록 출력 계약/프롬프트 및 의미 회귀 보강. 원문 인용 검증은 유지.
2. **안전한 기본값:** 참여자는 연결된 어르신 정보, 장소는 기관이 설정한 기본값, 목표는 사전 세션 계획에서 채움. 없는 값을 추측하지 않음.
3. **작성 최소화:** '실제로 보완해야 할 항목'만 묶고, 근거가 없는 의견수렴은 이유를 표시. 사실에 해당하는 선택지·문장 제안 후 사람 확인을 사용하고 자동 승인하지 않음.
4. **수정 최소화:** 문장별 근거 표시, 해당 문장만 수정하는 흐름. 전체 일지를 다시 쓰게 하지 않음.
5. **평가·계획:** 현재 사람 작성 정책을 유지하면서 사람 관찰/선택 입력을 돕기. 생성 범위를 확장하려면 기존 정책과 함께 검토.
6. **상태 정합성:** 확인 대기와 필드 보완 상태를 구분하고, 확정 직전에 빠진 항목을 명확히 안내. 근거 없는 칸까지 강제 입력하지 않음.
7. **날짜 명확성:** 과거 일지 재생성 시 상대 날짜 표현을 원래 활동일 기준으로 표시.

운영 확정 일지·승인·공개 설정은 수정하지 않았다. 점검 결과와 후속 과제만 기록했다.
