# 기억온(GiokOn) 웹 — 디자인 리뉴얼 스펙

---

## 0. 서비스 개요

- **기억온(GiokOn)**: 요양보호사가 어르신의 연대기(살아온 이야기)를 입력하면, AI가 어르신과 1:1 음성 회상 대화를 진행·기록하는 **인지활동 보조 플랫폼**.
- **⚠️ 비의료 서비스**: 의료기기가 아니며 질병 판정·의학적 소견 제공이 목적이 아니다. 모든 화면 카피는 "치료·효능·향상·호전" 같은 **의료 주장 표현을 쓰지 않고**, "인지활동·관찰 지표(참여도·응답률·발화량·주제 반응)" 언어를 쓴다. (코드 레벨 카피 린트로 강제 중)
- **이 웹의 범위**: 요양보호사·기관 관리자·보호자용 **관리 웹**. (어르신의 음성 대화 화면은 별도 **모바일 앱** 담당 — 이 문서 범위 밖.)

### 사용자(역할) 3종
| 역할 | 설명 | 진입 화면 |
|---|---|---|
| **요양보호사(caregiver)** | 어르신·세션·연대기·일지 관리, 대화 기록·분석 조회, 보호자 공개 선별 | `/caregiver` (사이드바 레이아웃) |
| **기관 관리자(org_admin)** | 요양보호사 권한 + 기관 정보 수정·구성원 전체 조회 (기관의 첫 가입자가 자동 부여) | `/caregiver` (동일 레이아웃, 일부 관리 권한 추가) |
| **보호자(guardian)** | 요양보호사가 **공개(커밋)한** 어르신 소식(일지·관찰 요약)만 열람 | `/guardian` (단일 페이지) |

## 1. 디자인 방향(외주 지침)

- **대상 화면 크기**: 데스크톱 웹 우선(관리 도구). 현재는 좌측 고정 사이드바(폭 240px) + 우측 본문 레이아웃. 반응형(태블릿) 고려 권장. (보호자 화면은 단일 컬럼 중앙 정렬 max-width 768px.)
- **접근성(KWCAG)**: 요양 도메인 특성상 접근성 준수. 현재 구현: 키보드 "본문으로 바로가기" 스킵 링크, 안전 알림 `role="alert" aria-live="assertive"`, 포커스 링(브랜드색), 아이콘 버튼 `aria-label`. 새 디자인도 대비·포커스·터치 타깃을 준수.
- **톤&매너**: 따뜻하고 신뢰감 있는 톤. 현재는 **브랜드 주황(brand) + 중립 회색(slate) + 시맨틱 색** 조합, 라운드 카드형 UI. (상세 토큰은 §디자인 시스템.)
- **한글 줄바꿈**: 다수 텍스트에 `word-break: keep-all`(단어 단위 줄바꿈) 적용 — 한국어 가독성 유지.

# 디자인 시스템 · 공통 컴포넌트

> 기술 스택 참고: **Tailwind CSS v3.4.19** + 커스텀 테마 토큰(`@giokon/theme` 단일 소스). 아래 HEX 값은 실제 코드에서 사용 중인 값이며, 표기 없는 기본 색은 Tailwind v3.4 기본 팔레트다.

---

## 디자인 시스템 개요 — 기억온(GiokOn) 웹 (요양보호사·보호자 관리 웹)

이 문서는 **요양보호사·보호자용 관리 웹**의 디자인 토큰과 공통 UI 컴포넌트 라이브러리 스펙이다. 어르신 대화 화면(warm/cream/elder-* 대형 타이포)은 별도의 모바일 앱 담당이며, 아래 색·타이포 토큰 중 `warm`·`cream`·`elder-*`·`mic`·`animation` 다수는 **테마 단일 소스(`@giokon/theme`)를 웹·모바일이 공유**하기 때문에 웹 Tailwind 설정에 함께 존재한다. 실제 요양보호사 웹 화면은 **`brand`(주황) + Tailwind `slate`(중립 회색) + 시맨틱 색(emerald/sky/amber/pink/red)** 조합만 사용한다. 각 토큰 옆에 실사용 여부를 표기한다.

- 폰트: **Pretendard** (한글 웹폰트) 우선. 폴백 `Apple SD Gothic Neo` → `Noto Sans KR` → `system-ui` → `sans-serif`.
- 본문 기본: 배경 `slate-50 (#f8fafc)`, 텍스트 `slate-900 (#0f172a)`, 안티에일리어싱 on, OpenType feature `ss01` 활성.
- 컴포넌트는 전부 라운드(둥근 모서리) + 얇은 테두리 + 소프트 그림자의 "카드형" 톤. 강조는 브랜드 주황, 나머지는 회색 톤.
- **비의료 카피 규칙**: 컴포넌트 라이브러리 자체에는 진단·효능 표현이 없다(유일한 한국어 문자열은 닫기 버튼의 `aria-label="닫기"`와 필수 표시 `*`뿐). 진단·효능 금지·관찰지표 언어 규칙은 이 프리미티브를 조합하는 상위 화면(분석·요양일지 등)의 카피 레벨에서 적용된다. 디자이너는 컴포넌트에 넣는 예시 텍스트에도 "치료·효과·호전" 등 의료 주장 표현을 쓰지 않는다.

## 8. 공통 컴포넌트 라이브러리

> 공통 클래스 유틸: 모든 컴포넌트는 `cn()`(= `clsx`)로 클래스를 병합하고, 마지막에 `className` prop을 덧대 개별 오버라이드를 허용한다. 각 컴포넌트는 나머지 HTML 속성(`...rest`)을 그대로 전달한다.

### 8-1. Button (`Button.tsx`)

기본 클래스(모든 버튼 공통):
`inline-flex items-center justify-center font-medium transition` + 비활성 `disabled:opacity-50 disabled:cursor-not-allowed` + 포커스 `focus:outline-none focus-visible:ring-2 focus-visible:ring-brand-300 focus-visible:ring-offset-2`.
- 정렬: 아이콘+텍스트 가로 중앙 정렬(아이콘은 lucide, 크기별 gap으로 간격).
- disabled 상태: 불투명도 50%, 커서 not-allowed(색은 그대로, 흐려짐).

**Variant (5종)** — `variant` prop, 기본값 `primary`:
| variant | 기본 | hover | active | 부가 |
|---|---|---|---|---|
| `primary` | 배경 `brand-500(#dc7a2c)`, 흰 텍스트 | `brand-600(#c06223)` | `brand-700(#9c4d20)` | `shadow-sm` + 브랜드 20% 컬러 그림자 |
| `secondary` | 배경 `slate-900(#0f172a)`, 흰 텍스트 | `slate-800(#1e293b)` | `slate-950(#020617)` | `shadow-sm` |
| `ghost` | 투명 배경, 텍스트 `slate-700(#334155)` | 배경 `slate-100(#f1f5f9)` | 배경 `slate-200(#e2e8f0)` | 그림자 없음 |
| `danger` | 배경 `red-500(#ef4444)`, 흰 텍스트 | `red-600(#dc2626)` | `red-700(#b91c1c)` | — |
| `outline` | 테두리 `slate-300(#cbd5e1)`, 배경 흰색, 텍스트 `slate-800(#1e293b)` | 배경 `slate-50(#f8fafc)` | 배경 `slate-100(#f1f5f9)` | 1px 테두리 |

**Size (4종)** — `size` prop, 기본값 `md`:
| size | 높이 | 좌우 패딩 | 글자 | 반경 | 아이콘 gap |
|---|---|---|---|---|---|
| `sm` | 32px(h-8) | 12px(px-3) | 14px(text-sm) | 6px(rounded-md) | 6px(gap-1.5) |
| `md` | 40px(h-10) | 16px(px-4) | 14px(text-sm) | 8px(rounded-lg) | 8px(gap-2) |
| `lg` | 48px(h-12) | 20px(px-5) | 16px(text-base) | 8px(rounded-lg) | 8px(gap-2) |
| `xl` | 56px(h-14) | 28px(px-7) | 18px(text-lg) | 12px(rounded-xl) | 10px(gap-2.5) |

디자이너 산출물: **5 variant × 4 size = 20 조합** + 각 조합의 hover/active/disabled/focus 상태.

### 8-3. Avatar (`Avatar.tsx`)

- 표시 내용: `initial(name)` = 이름을 trim 후 **마지막 2글자**(예: "김영자" → "영자", 빈 문자열 → "?").

**Size (4종)** — `size` prop, 기본값 `md`:

### 8-5. Dialog (모달) (`Dialog.tsx`)

중앙 정렬 모달. 구조(위→아래):
1. **오버레이 레이어**: `fixed inset-0 z-50`, `flex items-center justify-center`, 바깥 여백 `p-4(16px)`.
2. **백드롭**: `absolute inset-0`, 배경 `slate-900` 40% 불투명(`bg-slate-900/40`), `backdrop-blur-sm`(blur 4px), 진입 애니메이션 `fade-in-up`. **클릭 시 닫힘**.
3. **패널**: `relative w-full`, 흰 배경, `rounded-2xl(16px)`, `shadow-xl`, 테두리 `slate-200`, 진입 애니메이션 `fade-in-up`. 폭은 size로 결정.
   - **헤더**(`header`): `flex items-start justify-between p-5`, 하단 구분선 `border-b border-slate-100`.
     - 제목(`title` 있을 때, `h2`): `text-lg(18px) font-semibold text-slate-900`.
     - 설명(`description` 있을 때, `p`): `text-sm text-slate-500 mt-1`.
     - **닫기 버튼**: 우상단, lucide **`X`** 아이콘(size 18), `text-slate-400 hover:text-slate-600`, `p-1 rounded-md hover:bg-slate-100`, `aria-label="닫기"`.
   - **본문**(`div`): `p-5`, 최대 높이 `max-h-[70vh]`, 넘치면 세로 스크롤(`overflow-y-auto`). `children` 렌더.
   - **푸터**(`footer`, 옵션): `footer` prop 있을 때만. `flex justify-end gap-2 px-5 py-4`, 상단 구분선 `border-t border-slate-100`, 배경 `slate-50` 60% 불투명, 하단 모서리 `rounded-b-2xl`. 보통 버튼들이 우측 정렬로 들어감.

**Size (3종)** — `size` prop, 기본값 `lg`:
| size | 최대폭 |
|---|---|
| `md` | 448px(max-w-md) |
| `lg` | 672px(max-w-2xl) |
| `xl` | 896px(max-w-4xl) |

동작(인터랙션):
- `open=false`면 아무것도 렌더하지 않음(null).
- 열리면 `body` 스크롤 잠금(`overflow: hidden`), 닫히면 복원.
- **ESC 키**로 닫힘, **백드롭 클릭**으로 닫힘, 닫기 버튼으로 닫힘(모두 `onClose` 호출).

### 8-6. Input / Textarea / Field (`Input.tsx`)

**Input** (`<input>`):
- `h-10(40px) w-full rounded-lg(8px)`, 테두리 `slate-300(#cbd5e1)`, 배경 흰색, 좌우 패딩 `px-3(12px)`, `text-sm(14px) text-slate-900`, placeholder `text-slate-400(#94a3b8)`.
- 포커스: `focus:ring-2 ring-brand-300(#efbb81)` + `focus:border-brand-400(#e89a52)`, outline 제거.
- disabled: 배경 `slate-50`, 텍스트 `slate-400`.
- 타입은 표준 HTML input 속성 그대로(text/email/password/number 등 `...rest`로 전달).

**Textarea** (`<textarea>`):
- `min-h-[88px] w-full rounded-lg`, 테두리 `slate-300`, 배경 흰색, 패딩 `px-3 py-2(12/8px)`, `text-sm text-slate-900`, placeholder `text-slate-400`, 세로 리사이즈 허용(`resize-y`).
- 포커스·disabled 는 Input과 동일.

**Field** (라벨 래퍼, `<label>` 로 감쌈): Input/Textarea 등 자식을 감싸 라벨·필수표시·힌트/에러를 붙임.
| 파트 | 스펙 |
|---|---|
| 라벨 | `text-sm(14px) font-medium(500) text-slate-700`, 하단 여백 `mb-1.5(6px)` |
| 필수 표시 | `required=true`일 때 라벨 뒤에 `*`, 색 `text-red-500(#ef4444)`, `ml-0.5` |
| 자식 | Input/Textarea/Select 등 (`children`) |
| 에러 | `error` 있을 때: `text-xs(12px) text-red-500 mt-1` |
| 힌트 | `error`가 없고 `hint`만 있을 때: `text-xs text-slate-500 mt-1` (에러가 있으면 힌트는 숨김) |

Field props: `label`(필수), `required?`, `hint?`, `error?`, `children`.

### 8-7. Toast (`Toast.tsx` — `ToastShelf`)

전역 토스트 알림. 스토어(Zustand)의 `toasts` 배열을 구독해 렌더하는 **고정 위치 스택**.
- **컨테이너**: `fixed bottom-4 right-4`(우하단 16px), `z-[60]`(다이얼로그 z-50보다 위), `flex flex-col gap-2(8px)`, 최대폭 `max-w-sm(384px)`. 여러 토스트가 세로로 쌓임(위로 누적).
- **각 토스트 카드**: `flex items-start gap-3(12px) rounded-lg(8px) border shadow-sm px-3.5 py-3(14/12px)`, 진입 애니메이션 `fade-in-up`.
  - **아이콘**(lucide, size 18, `mt-0.5 shrink-0`): 종류별로 아래.
  - **메시지**: `flex-1 text-sm(14px) font-medium leading-relaxed`.
  - **닫기 버튼**: lucide **`X`**(size 14), `opacity-60 hover:opacity-100`, `aria-label="닫기"`, `shrink-0`. 클릭 시 해당 토스트 제거.

**Kind (3종)** — 스토어 `toast(kind, message)`의 kind:
| kind | 아이콘(lucide) | 테두리 | 배경 | 텍스트 |
|---|---|---|---|---|
| `success` | `CheckCircle2` | `emerald-200(#a7f3d0)` | `emerald-50(#ecfdf5)` | `emerald-900(#064e3b)` |
| `error` | `AlertCircle` | `red-200(#fecaca)` | `red-50(#fef2f2)` | `red-900(#7f1d1d)` |
| `info` | `Info` | `slate-200(#e2e8f0)` | 흰색 | `slate-900(#0f172a)` |

동작: 토스트는 생성 후 **3200ms(3.2초)** 뒤 자동으로 사라진다(수동 닫기 버튼도 있음). 메시지 텍스트는 호출 시점에 주입되는 동적 값(고정 카피 아님).

2. 입력 필드(children)
3. 그 아래: `error`가 있으면 `text-xs text-red-500`, 없고 `hint`가 있으면 `text-xs text-slate-500`(상단 여백 4px). 인증 화면에서는 error 미사용, hint만 사용.

### 0.6 `Input` 컴포넌트
높이 40px(`h-10`), 100% 폭, `rounded-lg`(8px), 테두리 `slate-300`, 흰 배경, 좌우 패딩 12px, `text-sm`, 텍스트 `slate-900`, 플레이스홀더 `slate-400`. 포커스: `ring-2 ring-brand-300` + 테두리 `brand-400`. 비활성: 배경 `slate-50`, 텍스트 `slate-400`.

### 0.7 `Button` 컴포넌트
- 기본 스타일: inline-flex 중앙정렬, `font-medium`, transition, `disabled:opacity-50 disabled:cursor-not-allowed`, 포커스 링 `ring-2 ring-brand-300 ring-offset-2`.
- variant: **primary**(기본) = 배경 `brand-500`(#dc7a2c)/흰 글자/hover `brand-600`/active `brand-700`+그림자; **outline** = 흰 배경/테두리 `slate-300`/글자 `slate-800`/hover `slate-50`; (그 외 secondary·ghost·danger 존재하나 인증 화면 미사용).
- size: 인증 화면 주 버튼은 **`lg`** = 높이 48px(`h-12`), `text-base`, `rounded-lg`, 아이콘 간격 8px. (코드상 `size="lg"`와 `className="h-12"` 병기.)
- 인증 주요 버튼은 모두 `w-full`(카드 전체 폭).

### 0.8 `Toast` (알림) 컴포넌트 — 전 화면 공통 피드백
- 위치: 화면 **우하단 고정**(`bottom-4 right-4`), z-index 60, 세로 스택, 최대 폭 `max-w-sm`.
- 카드: `rounded-lg` 테두리+`shadow-sm`, 패딩 상하 12px/좌우 14px, 등장 애니메이션 `fade-in-up`(아래→위 10px, 0.3s).
- 구성: 좌측 아이콘 18px + 메시지(`text-sm font-medium`) + 우측 닫기 **`X`**(14px, `aria-label="닫기"`, opacity 60→100 hover).
- 톤/아이콘: 성공=lucide `CheckCircle2`, 테두리/배경/글자 emerald(`emerald-200`/`emerald-50`/`emerald-900`); 실패=`AlertCircle`, red(`red-200`/`red-50`/`red-900`); 정보=`Info`, 흰 배경/slate.

### 0.9 라우팅 · 접근 가드 (공통 규칙)
- 공개(비로그인 접근 가능): `/`, `/login`, `/find-id`, `/forgot-password`, `/reset-password`, `/onboarding`, `/privacy`, `/terms`.

- `/login`: 이미 로그인 세션이 있으면 역할에 따라 자동 이동(온보딩 미완료→`/onboarding`, guardian→`/guardian`, 그 외→`/caregiver`). 세션 판별 중(`loading`)에는 아무것도 렌더하지 않음(빈 화면, 깜빡임 방지).

## 3. 아이디(이메일) 찾기 (FindIdPage) — URL `/find-id`

# 공통 — AI 에이전트 패널 (AgentPanel)

요양보호사·보호자 화면 우하단 **플로팅 원형 버튼**(`Bot`; 요양보호사=주황, 보호자=보라, `aria-label="AI 도우미 열기"`). 클릭 시 우하단 **채팅 패널**(폭 360px, 최대높이 70vh) 열림.
- **헤더**: `Bot` + "AI 도우미" + 우측 닫기(X).
- **AI 고지문**(상시): 회색 작은 글씨(면책·투명성 문구).
- **(요양보호사)** 대상 어르신 선택 칩 행("대상:" + 어르신 칩).
- **대화 영역**: 사용자=검은 말풍선(우), 에이전트=회색 말풍선(좌). 초기 예시 안내:
  - 요양보호사: "예: "점심 잘 드시고 산책하셨어 — 일지 초안 만들어줘" / "오늘 일지 공개해줘" / "최근 분석 공개해줘""
  - 보호자: "예: "최근 소식 요약해줘""
- **실행 전 사람 확인 게이트**(핵심): 쓰기 작업(일지 초안 저장·확정 일지 공개·세션 분석 공개)은 즉시 실행하지 않고 **주황 확인 카드** "실행 확인 — (작업명) (○○ 어르신)" + "**실행**"/"취소" 버튼으로 사람이 확인해야 실행. (읽기형 "소식 설명"은 즉시.)
- **입력창** + 전송(`Send`). 미연동 시 "Supabase 연동 후 이용할 수 있어요."
- ⚠️ 현재 **mock(규칙 기반)** — 실 LLM 연동 예정. 디자인은 대화형 챗봇 패널로.

# 공통 상태 · 규칙 (전 화면 적용)
