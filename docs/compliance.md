## 1. 개인정보보호법(PIPA)

### 1.1 민감정보(건강·음성) — 별도 동의 (필수)
- **요건**: 건강정보는 「개인정보 보호법」 제23조 **민감정보**. 다른 동의와 **분리된 별도 동의**(거부권·불이익 고지 후) 필요. 회상대화 음성은 (a) 건강·정서가 드러나는 민감정보이자 (b) 화자 식별 특징 추출 시 시행령상 **생체인식정보(민감정보)** 가능 → 보수적으로 별도 동의 대상. 위반 시 **5년 이하 징역/5천만원 이하 벌금**.
- **구현**: 온보딩 동의서에 "민감정보(건강·음성) 수집·이용" **별도 체크박스**. 음성 동의 시 동의 사실 녹취·보관. → `consents` 테이블(§5).
- 출처: [개인정보 보호법(국가법령정보센터)](https://www.law.go.kr/LSW/lsInfoP.do?lsId=011357) · [민감정보 처리(찾기쉬운 생활법령)](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?csmSeq=1257&ccfNo=2&cciNo=3&cnpClsNo=1)

### 1.2 동의능력·대리동의 (치매 어르신) — 법적 공백 보완
- **현황**: PIPA 제22조의2 **법정대리인 동의는 만 14세 미만 아동 전용**. **성인 의사무능력자(치매)의 대리 동의 규정은 PIPA에 없음.** 성인 대리는 **민법 성년후견/한정후견(성년후견인)** 체계로만 가능.
- **설계**: ① 경증·의사능력 있는 어르신 = **본인 동의** 원칙. ② 의사능력 없는 경우 = **성년후견인(법정) 확인** 경로. ③ 후견 미개시 시 요양원 직원/가족 임의 대리는 법적 근거 취약 → **동의능력 판정 절차 + 보호자 확인 + 위험고지 + 최소수집** 폴백. (심사 지적 가능성 높은 영역 — 외부 법무 감수 병행.)
- **구현**: 동의 플로우에 의사능력 판정 문항 + 동의 주체(본인/후견인/보호자)·근거 기록.
- 출처: [제22조의2(CaseNote)](https://casenote.kr/%EB%B2%95%EB%A0%B9/%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4_%EB%B3%B4%ED%98%B8%EB%B2%95/%EC%A0%9C22%EC%A1%B0%EC%9D%982) · [성년후견 사무(찾기쉬운 생활법령)](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=694&ccfNo=3&cciNo=2&cnpClsNo=2)

### 1.3 수집·이용·보관·파기
- **요건**: 목적·항목·보유기간·거부권 고지 후 동의(제15조), 목적 달성 시 **지체 없이 파기**(제21조). 보유기간 명시·파기 절차 마련.
- **구현**: 음성 원본·전사텍스트·대화로그 **보유기간·자동 파기 정책** 명확화(예: 대화 요약 보관, 원음성 즉시/N일 삭제 — `docs/infrastructure.md` 보관/파기). 데이터 처리목록(ROPA) 유지.

### 1.4 개인정보 처리방침 (제30조) — 의무 기재 8항목 + 위탁 + 국외이전
- ① 처리목적 ② 처리·보유기간 ③ 파기절차·방법 ④ **처리위탁**(Supabase/LLM/STT/TTS) ⑤ 정보주체·법정대리인 권리·행사방법 ⑥ 안전성 확보조치 ⑦ **CPO 성명·연락처** ⑧ 변경사항. **국외이전** 시 이전받는 자·목적·항목·기간·거부방법(제28조의8).
- **구현**: 처리방침·이용약관 문서화 + 웹/앱 상시 노출(회원가입·설정). 문서 감수는 외부 법무.
- 출처: [제30조(CaseNote)](https://casenote.kr/%EB%B2%95%EB%A0%B9/%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4_%EB%B3%B4%ED%98%B8%EB%B2%95/%EC%A0%9C30%EC%A1%B0)

### 1.5 PIA · CPO
- **PIA**: 법정 의무는 **공공기관 한정**(민간 자율). 단 공공 복지관/지자체가 운영주체로 5만명 이상 민감정보 처리 시 그 기관에 의무 발생 → **B2G 납품 시 PIA 협조·산출물 제공** 대비. 출처: [영향평가(PIPC)](https://www.pipc.go.kr/np/default/page.do?mCode=D050020000)
- **CPO**: 지정 **의무**(초기 대표/실무자 가능). 전문 CPO 자격요건은 대규모 처리자 한정이라 스타트업 규모는 미해당 가능. 처리방침에 성명·연락처 공개. (지정은 외부/경영.)

## 2. 데이터 국내 보관 / 국외이전
- **요건**: 국외이전(제28조의8)은 별도 동의 / 처리위탁·보관은 **처리방침 공개로 갈음** 가능 등. **Supabase 도쿄 리전 = 국외 보관.** 민감정보 + 정부사업 맥락에서는 **국내(서울) 리전 이전이 안전**하며, 공공 클라우드 조달은 CSAP 전제로 사실상 국내 요건.
- **결정(확정)**: **Supabase 서울(ap-northeast-2) 신규 프로젝트로 이전**(M10.1). 국외로 나가는 LLM/STT/TTS는 국외이전 동의·처리방침 명시 + 위수탁계약(벤더 데이터 처리위치·재학습 여부 확인).
- 출처: [제28조의8(CaseNote)](https://casenote.kr/%EB%B2%95%EB%A0%B9/%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4_%EB%B3%B4%ED%98%B8%EB%B2%95/%EC%A0%9C28%EC%A1%B0%EC%9D%988) · [CSAP(KISA)](https://www.kisa.or.kr/1050603)

### 5.2 계정 삭제 처리 절차(멀티테넌시·보존 정합)
> 단순 `DELETE users`는 프로필→연대기→동의까지 cascade 파기된다. 기관 귀속·증빙 보존을
> 위해 **재귀속 우선** 절차를 따른다(코드: `buildAccountDeletionPlan`).
1. 소속 어르신 데이터(profiles 및 하위)를 **기관 관리자에게 재귀속**(파기 아님).
2. 동의 이력은 보존, `user_id`만 SET NULL로 **익명화**(증빙 유지).
3. 음성 원본 등 민감정보 파기, 감사로그는 **2년 보존**.
4. 위 처리 후 계정 식별정보(auth/public.users) 파기.

> **알려진 정합 강화(v1.x)**: 현재 데이터 4테이블의 `user_id`는 초기 스키마상
> `ON DELETE CASCADE`이므로 위 1·2단계는 **애플리케이션 절차(재귀속)로 보장**한다.
> 향후 `user_id`를 `SET NULL`(+ 조직 기준 복합키)로 전환해 DB 레벨에서도 강제할 예정.
