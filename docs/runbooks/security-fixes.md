## 운영 DB 를 다룰 때의 원칙

- 운영 DDL 은 **사용자 승인 후 한 건씩** 적용하고, 같은 트랜잭션에 이력을 남긴다(CLI `db query --linked --file`).
- MCP `apply_migration` 은 **적용 시각**으로 이력을 기록한다 — 쓴 뒤엔 저장소 파일명 버전으로 맞춘다(안 하면 `db push` 가 재실행하려 든다).
- 적용 여부는 추측하지 않고 카탈로그를 조회해 확인한다(MCP `execute_sql` 은 읽기만).
- 격리 DB 회귀(`supabase/tests/run-rls-regression.sh`)는 **운영 DB 에서 실행하지 않는다**.
