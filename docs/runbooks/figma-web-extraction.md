## ⚠️ 좌표 함정 (실측으로 확인)

1. **텍스트 노드의 `y` 는 라인박스 top 이다.** 잉크 중심 = `y + lineHeight/2`.
   `get_metadata` 의 `h` 는 **라인박스가 아니라 렌더 bbox** 라 그대로 쓰면 안 된다
   (예: 161:214 `h=23.02` 인데 실제 라인박스는 30 — export 잉크로 확인).
   높이는 `get_design_context` 의 `leading-[…]` × 줄 수로 계산한다.
2. **수동 리사이즈된 텍스트 프레임**은 `h` 가 줄 수×lineHeight 보다 크다(1:13 h1 = 160 vs 140).
   이때도 잉크는 위에서부터 채워지므로 **줄 수×lineHeight** 가 맞다.
3. **반전·회전 노드는 `get_metadata` 좌표가 렌더 위치가 아니다.**
   (161:322 합류 배너 metadata y=937 → 실제 881 · 어르신 카드 chevron metadata x=1278 → 실제 1266)
   `get_design_context` 의 명시 `top/left`, 또는 export PNG 잉크 실측을 믿는다.
4. **Figma 는 대부분의 텍스트에 lineHeight 를 지정하지 않는다(auto ≈ 1.17~1.21).**
   토큰 기본값(`text-w-sub`=18/28 등)을 그대로 쓰면 라인박스가 커져 **잉크가 2~3px 내려간다.**
   실측 라인박스(24·21·19·26 …)를 `leading-[…]` 로 명시한다.
5. **Figma 자체 드리프트**가 흔하다(같은 폼의 입력 x 가 432/433/434, 통계 카드 y 656/657,
   최근 대화 행 pitch 130/144/150). 코드에서는 통일하고, `accept` 사유로 남긴다.
6. **DOM 대조는 글자 크기를 못 잡는다** — `fontSize` 는 우리가 스펙에 적은 값을 되읽을 뿐이다.
   크기·굵기가 틀렸는지는 **잉크 폭·높이 비율**로만 드러난다(연결 후 50:528 에서 6곳을 이렇게
   잡았다: 이름 30→35 · 생년월일/기관 20→24 · 연결 정보/연결 해제/다시 연결하기 20→22).
   한글 잉크 높이 ≈ 0.878em 이라 `실제크기 ≈ 적은크기 × (Figma 잉크높이 / 구현 잉크높이)`.
7. **여러 줄 상자의 마지막 빈 줄** — 시안 텍스트가 줄바꿈으로 끝나면 상자가 한 줄 더 높다
   (55:1337 요약 6줄 중 1줄이 빈 줄 · 69:322 부제 2줄 중 1줄이 빈 줄). 빈 줄을 흉내 내지 말고
   `topEdge` 로 위 모서리를 맞추거나, 그 빈 줄을 뺀 실제 간격을 쓴다.
8. **잉크는 줄상자 안에서 Figma 가 CSS 보다 조금 아래**에 앉는다(21.02 줄상자에서 2.25px).
   상자 top 을 옮기면 형제 좌표가 흔들리므로, **줄높이를 넓혀(21→25.5) 잉크만 내리고**
   위 모서리는 그대로 두는 편이 안전하다(프로브는 `topEdge`).
9. **한 노드 안에 크기가 섞여 있다** — `+ 새 어르신 연결`(+ 만 25, 글자 18) ·
   `어린 시절 / 가족`(낱말 SemiBold, 구분자 Regular). `get_design_context` 가 span 으로 알려 준다.

### 모달 프레임 재는 법
모달 프레임(`196:271`·`198:991` …)은 캔버스 좌표가 아니라 **카드 로컬 좌표**로 그려져 있고,
화면 어디에 뜨는지는 디자인에 없다. 그래서 실측표의 화면에 `origin`(카드 선택자)을 준다.
- `figma-audit.mjs` 가 그 요소의 좌상단을 빼고 재고,
- `figma-shots.mjs` 가 그 박스(`width`×`height`)만 잘라 export 와 1:1 로 맞춘다.
  ⚠️ 모달 캡처는 **뷰포트를 넉넉히(≥1600) 잡는다** — 카드가 뷰포트보다 크면 스크롤
  컨테이너 안에서 위가 잘린 채 찍혀 잉크 대조가 통째로 어긋난다(실제로 겪음).
- `scripts/crop-web-figma-assets.py` 도 모달 export 는 `FRAME_WIDTH` 로 배율 기준을 바꾼다
  (화면 export 는 1440, 모달 export 는 카드 폭).
- ⚠️ **어르신 말풍선(`187:1286` 등)은 좌우 반전 노드**라 metadata x 가 왼쪽이 아니라
  **오른끝**이다(1226 → 실제 왼쪽 772). 반전 노드는 항상 export 잉크로 확인한다.
- ⚠️ **부품(`components/*.png`) export 는 아직 @1x** 다. `figma-ink.py` 가 배율을 맞춰 비교하니
  대조는 되지만 잘라 쓴 아이콘은 1x 라 고해상도 화면에서 부드럽다 — 같은 파일명으로 @4x 를
  덮어써 주면 그대로 선명해진다(현재 해당: `icon-photo-upload`).

## 시안에 없는 화면 (직접 만든 것)

새 Figma 가 **버튼은 그렸지만 그 다음 화면을 그리지 않은** 자리다. 임의 재디자인이 아니라
**끊긴 흐름을 잇는 최소 구현**이며, 시안이 생기면 그 단계만 교체한다. 정밀 대조 프로브는
붙이지 않는다(대조할 노드가 없다) — `check:design` 정규식으로만 고정한다.

| 자리 | 시안이 그린 데까지 | 직접 만든 것 |
|---|---|---|
| 메시지 작성 | "메시지 보내기" 버튼 + 이용 안내 모달 `69:195`("보내기 전 확인해 주세요") | 안내 확인 후 열리는 작성 폼(`components/guardian-message.tsx` `ComposeDialog`) — 같은 모달 언어(카드 r10 · 라벨 SemiBold 22 · 버튼 57) |
| 알림 드롭다운 | 탑바 벨 + 개수 배지(18 @1059,60, 시안 숫자 3) | 벨을 눌렀을 때의 목록(`shell/TopBar.tsx`) — 전용 알림 화면이 디자인에 없다 |

## 주의

- 컨테이너 egress 가 `www.figma.com` 을 막아 **스크린샷 URL 다운로드가 불가**하다.
  `get_screenshot` 은 `enableBase64Response: true` 로 인라인 수신하거나, 위 export 에셋을 쓴다.
- 이 파일은 Figma Variables 를 쓰지 않는다(`get_variable_defs` → `{}`). **fill 실측값**을 토큰으로 승격한다.
