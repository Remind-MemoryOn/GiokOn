# ai-safety.md — AI 안전·신뢰성

> 목표: 취약계층(치매 어르신) 대상 AI 대화의 안전. 위기 에스컬레이션·가드레일·투명성(AI기본법 2026)·
> 검수. **비의료 원칙 유지**(진단·의학적 판정 금지 — `docs/compliance.md` §3). 관련: PLAN §2′ M12, M7.

## 1. 위기 감지 · 사람 에스컬레이션 (M12.1)
- **감지 대상**: 자살·자해·학대·방임·응급(신체 위급) 표현.
- **동작**: 자동 "진단" 금지. 대신 ⓐ 안전한 대화 전환·안내, ⓑ **사람(보호자/기관 담당)에게 에스컬레이션 알림**, ⓒ 이벤트 로깅(감사). 필요 시 공공 위기 지원 안내 문구.
- 근거: 취약계층 안전장치는 과기정통부 AI 윤리기준·AI기본법 안전성 의무와 정합.

## 2. 가드레일 (M12.2)
- **입력/출력 필터**: 유해·부적절·차별·개인정보 유출·환각 응답 차단.
- **의학적 조언 회피**: 진단·처방·치료 조언 금지 + 면책("의료 상담은 전문가에게"). 
- 주제 안전규칙(기존 T7.4 확장): 동일 주제 3회+ 금지, 고통(사별·전쟁 등) 키워드 부드러운 전환, 짧은 답변 시 쉬운 질문.
- 거절·종료 옵션, 세션 자동 종료(침묵·턴 초과).

## 3. 투명성 (M12.3) — AI 기본법(2026.1 시행)
- **AI 이용 사전 고지**: "AI가 응답합니다"를 어르신·요양보호사에게 명시(대화 시작·설정).
- **생성물 표시**: AI 생성 콘텐츠 표시(로그·리포트).
- **해외 LLM 사용 시**: 국내대리인·데이터 처리(국외이전) 고지(→ `docs/compliance.md` §2).
- 참고: AI기본법 '고영향 AI'에 **의료 포함** — 본 제품은 비의료 설계지만 의료 인접·취약계층이라 **보수적으로 투명성·안전성 선제 적용**.
- 출처: [AI 윤리기준(과기정통부)](https://www.msit.go.kr/bbs/view.do?mId=113&bbsSeqNo=94&nttSeqNo=3179742) · [인공지능기본법(국가법령정보센터)](https://www.law.go.kr/lsInfoP.do?lsiSeq=268543)

## 4. 검수·평가 (M12.4)
- **human-in-the-loop**: 대화 로그 샘플 검수 프로세스(부적절·위기 놓침 점검).
- **안전 평가셋·레드팀**: 위기·유해·탈옥 프롬프트 테스트셋으로 회귀 평가. 모델 교체(프런티어 벤치마크) 시 한국어 품질·안전·지연·비용 재평가.
- Structured Outputs로 형식 안정성(파싱 실패 제거).

## 5. 구현 매핑
- Edge Function `session-respond`에 안전 레이어(입력 필터→LLM→출력 필터→위기 스캔→에스컬레이션 훅).
- `packages/core`에 안전규칙·위기 키워드·에스컬레이션 도메인. 알림 채널(보호자/기관)·audit 로깅.

## 6. 검증
- 위기표현 테스트셋 → 에스컬레이션·안전응답·로깅 확인, 유해/의학조언 프롬프트 차단, AI 고지 노출, 레드팀 회귀 통과.
