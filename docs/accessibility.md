# accessibility.md — 접근성·품질

> 목표: 웹·앱 **KWCAG 2.2** 준수(정부지원·공공 시 사실상 의무) + 웹접근성 품질인증 로드맵 +
> 자동/수동 테스트. 어르신 사용자 특성상 접근성은 제품 핵심. 관련: PLAN §2′ M13, `docs/design.md`.

## 1. KWCAG 2.2 준수 (M13.1)
- **기준**: 한국형 웹 콘텐츠 접근성 지침 **KWCAG 2.2**(4원칙·14지침·**33개 검사항목**), 「지능정보화기본법」·「장애인차별금지법」상 의무. 모바일 앱은 **모바일 앱 접근성 지침**.
- **어르신 UX 강제**: 본문 텍스트 ≥ 18pt, 터치 타깃 ≥ 60px, 고대비(명도대비 충족), 음성 우선(TTS 자동재생) + 텍스트 동시 표시, 조작 최소화(마이크 1버튼).
- 웹(`apps/web`, 요양보호사)·모바일(`apps/mobile`, 어르신) **모두 준수**(기존엔 어르신 화면만 언급 → 웹 포함으로 상향).
- 출처: [KWCAG 2.2(a11ykr)](https://a11ykr.github.io/kwcag22/) · [웹접근성 품질인증(KWACC)](http://www.kwacc.or.kr/Accessibility/Certification)

## 2. 인증·테스트 (M13.2)
- **웹접근성 품질인증**(디지털포용법 제21조) 로드맵 — 공공 납품 시 가점/요건(심사는 외부).
- **자동 검사**: axe(웹)·접근성 린트 CI 게이트. 
- **수동 점검**: 스크린리더(NVDA/VoiceOver), 키보드 내비, 명도대비, 확대. **어르신 사용성 테스트**(실사용자).

## 3. 테스트 파이프라인 (M13.3)
- 단위(vitest) + 통합 + **E2E(Playwright)** + **RLS(pgTAP)** + **접근성(axe)** — CI 필수 게이트.
- 커버리지 목표, 시각적 회귀(옵션), 성능(Lighthouse/CWV — Claude Design 비교와 연동).

## 4. Claude Design 트랙과의 연동
- Claude Design 프론트(M15)는 **접근성 내장 컴포넌트**로 구현 → KWCAG·axe·Lighthouse 점수를 외부 업체본과 **비교표**(정량)로 산출.

## 5. 검증
- 핵심 화면 axe 0 violations, KWCAG 33항목 체크리스트, 스크린리더 스팟체크, 어르신 사용성 테스트 결과, Lighthouse 접근성/성능 점수.

## 6. 웹 자동 검사 구현 (2026-09-01)

§2 의 "axe CI 게이트" 를 실제로 만들었다. **`pnpm check:a11y`**
(`apps/web/scripts/a11y-audit.mjs`) — 감사 빌드(`dist-audit`, Figma 정밀 대조와 같은
스텁·같은 라우트)를 띄우고 **이관 완료 52화면 전부**에 axe-core 를 돌린다.

- 규칙: `wcag2a` · `wcag2aa` · `wcag21a` · `wcag21aa`.
- axe 가 못 보는 **모달 키보드 동작**을 함께 검증한다(6종): 열면 초점이 안으로
  들어가는가 · Tab/Shift+Tab 이 밖으로 새지 않는가 · Esc 로 닫히는가.
  구현은 `apps/web/src/lib/modalA11y.ts`(`useModalA11y`) — 공용 `Dialog` 와 시안 치수를
  직접 그린 모달 3종이 같은 키보드 동작을 공유한다. **시각 디자인은 건드리지 않는다.**
- 회귀 확인: 검색 입력의 `aria-label` 을 지우면 즉시 위반 2건으로 실패한다.

### 첫 실행에서 잡은 것
- **탑바 어르신 검색 입력에 라벨이 없었다**(22화면, `critical`). 시안이 안내문 없이
  돋보기만 두는 디자인이라 `placeholder` 도 비어 있어 접근 가능한 이름이 아예 없었다 →
  `aria-label="어르신 검색"`(렌더 무변화).
- **모달 4종이 초점을 관리하지 않았다** — 열어도 초점이 뒤 페이지에 남고 Tab 이 모달
  밖으로 샜다. 시안 치수 모달 3종은 Esc 도 없었다 → `useModalA11y` 로 통일.
- 제목을 직접 그리는 모달(`Dialog`에 `title` 을 안 주는 4곳)은 접근 가능한 이름이
  없었다 → `label` prop 신설.

### ⏳ 사용자 결정 대기 — 명도대비

axe 가 **색 쌍 31종 · 581곳**에서 KWCAG/WCAG 최소 대비 미달을 보고한다. 색은 시안이
정한 값이라 **코드가 임의로 바꾸지 않는다**(재디자인 금지 원칙) → 게이트는 실패시키지
않고 **표로 보고**만 한다. 결정이 나면 토큰 한 곳만 고치면 된다.

주요 항목과 **색상(hue)을 유지한 최소 보정값**:

| 현재 | 배경 | 대비 | 필요 | 곳 | 최소 보정 | 보정 후 | 용도 |
|---|---|---|---|---|---|---|---|
| `#7b7c7c` | `#ffffff` | 4.18 | 4.5 | 334 | `#757676` | 4.56 | `ink-500` 본문·보조 텍스트 |
| `#e9822b` | `#ffffff` | 2.72 | 4.5 | 66 | `#af6220` | 4.57 | accent 텍스트 |
| `#ffffff` | `#e9822b` | 2.72 | 4.5 | 38 | 배경 `#b85a0d` | 4.66 | 주황 버튼 라벨 |
| `#e9822b` | `#fdf3ea` | 2.49 | 4.5 | 27 | `#a55c1f` | 4.62 | 연한 주황 배지 |
| `#60bd66` | `#eff8f0` | 2.15 | 4.5 | 30 | `#3f7d43` | 4.58 | 초록 배지 |
| `#d5379b` | `#fbebf5` | 3.77 | 4.5 | 8 | `#be318a` | 4.58 | 분홍 배지 |
| `#1cb2d0` | `#e8f7fa` | 2.29 | 4.5 | 5 | `#13798d` | 4.61 | 하늘 배지 |

- **`ink-500` 만 고쳐도 581곳 중 334곳(58%)이 해소**되고, 변화량은 5% 명도(육안으로
  거의 구분되지 않는다) — 가장 값싼 개선이다.
- accent 계열은 **브랜드 색을 바꾸는 결정**이라 별도 판단이 필요하다. 대안: 주황을
  큰 글자(≥24px 또는 굵은 ≥19px)에만 쓰면 기준이 3:1 로 낮아지지만 2.72 라 여전히 미달.
- 정부심사(웹접근성 품질인증)를 목표로 한다면 §1 의 "고대비" 요건상 **해소가 사실상 필수**다.
