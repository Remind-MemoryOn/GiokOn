# tasks.md

## 1. 개발 목표 요약

| 항목 | 내용 |
|---|---|
| 최종 목표 | 연대기 입력 → LLM 대화 → TTS 출력 → STT 입력 → 세션 로그 저장 핵심 파이프라인 완성 + 현장 파일럿 1회 |
| 개발 기간 | 2026.04.14 ~ 2026.06.09 (8주) |
| 발표일 | 2026.06.11 |
| 팀 구성 | 팀장(풀스택·AI) / 팀원 A(프론트·앱) / 팀원 B(프론트·웹·기획) |
| 완성 기준 | Must 4개 + Should 핵심 3개 (S-01·S-02·S-03) 동작 확인 |

**원칙: 기능 욕심보다 완성도 우선**
- 8주 안에 시연 가능한 수준 우선
- Should 기능은 Must 완성 후 여유 있을 때 추가
- 파일럿은 7주차 고정. 이 날짜는 뒤로 밀지 않는다
