# 기억온 진행 현황 요약

기준일: 2026-09-22 · 대상: `C:\GiokOn` 로컬 작업 폴더

> 이 문서는 현재 코드와 `AGENTS.md`, 개발 실행 기록을 요약한다. **로컬 구현·자동 검사 통과는 운영 배포나 실제 어르신 데이터로 검증 완료를 뜻하지 않는다.** 최근 웹 변경은 미커밋·미배포이며 GitHub에 올리지 않았다.

## 현재 구현된 기반

- `pnpm` 모노레포: 요양보호사·보호자 관리 웹, 어르신 대화 모바일 앱, 공통 도메인·데이터 패키지, 음성 중계 서버.
- Supabase Auth, 기관·역할·담당 어르신 접근 통제(RLS), 어르신 등록·연결, 동의·연대기·세션·일지·보호자 공개 흐름의 코드 기반.
- 모바일 대화: Gemini Live 연동과 음성 중계 경로, 자동 청취→응답→재생 루프, 담당자 시작·일시정지·재개·회수, 전사 출처 구분, 중단·재생 실패 대응을 로컬 구현했다. 서버 검증 텍스트→Clova 재생은 출시 목표 경로이며 **실제 공급자·기기·운영 환경의 종단 검증은 남아 있다.**
- 종료 세션 분석·일지용 `session-report` 함수와 웹의 초안 미리보기·명시적 적용 경로가 있다. 사용자 확인·최종 저장·보호자 공개는 별도 동작으로 유지한다.

## 최근 로컬 웹 변경

- 요양보호사 사이드바의 로그아웃 노출·메뉴 스크롤을 조정하고, `요양일지`를 `프로그램일지`, 분석 진입을 `대화관찰리포트`로 표시했다. 변경된 메뉴명의 글꼴 크기·두께도 다른 항목과 통일했다.
- 프로그램일지 새 작성 화면의 음성 입력·사진 첨부 UI를 제거했다. 기존 저장 자료·DB 필드는 삭제하지 않았다. 현재 직접 입력 초안은 규칙 기반이며, 실제 회상 대화 기반 AI 초안과 구분해 표시한다.
- 담당 어르신 대화 모니터링 화면은 최대 5명 카드로 **저장 완료된 발화**를 재조회한다. 말하는 중간의 부분 STT 실시간 스트리밍은 아니다.
- 어르신 기본 정보의 긴 값은 카드 안에서 말줄임하고 `전체 보기`에서 원문을 읽게 했다. `철회` 클릭이 없는 경로를 통해 홈으로 가던 문제는 전용 동의 관리 화면·개별 확인 단계로 연결했다. 실제 계정의 철회 동작은 아직 시험하지 않았다.
- 보호자·담당자 화면의 일부 오류/빈 상태 표시와 프로그램일지 입력 원문 비교 등은 로컬에서 보강했으나, 재조회 시 원문 비교 이력 복원까지 완료한 것은 아니다.

## 출시 전 남은 핵심 작업

1. **DB·운영 적용:** 전사 출처 저장용 로컬 마이그레이션의 운영 적용과 이력 대조, 음성 중계 호스팅·WSS·배포/롤백 검증. 운영 DB를 임의로 변경하지 않는다.
2. **대화 현장 검증:** 실제 Gemini·Clova·설치 앱으로 자동 대화, 긴 침묵·사투리·소음·무응답, 전화/Bluetooth·백그라운드, 중단 후 맥락 복구, 저장 실패를 확인한다. 재생 관측·복구 이력의 영속화와 앱 재시작 후 복구는 후속이다.
3. **기록 신뢰성:** 담당자 확인·정정 이력, 개인화 근거, AI 분석·일지 초안의 누락/날조 여부, 최종 저장과 보호자 공개·철회 실패 경로를 실데이터로 검증한다.
4. **웹 종단 시험:** 실계정으로 가입→어르신 등록→동의→세션→모니터링→일지→보호자 공개를 확인한다. 특히 새 동의 철회 화면과 화면 크기별 배치를 직접 확인해야 한다.
5. **출시 운영:** 계측·오류 알림, 접근성, 실기기 장시간 시험, 계정 삭제/소셜 복귀, 기능 중지·롤백 절차를 마친다.
