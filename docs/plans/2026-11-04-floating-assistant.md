### 안전·원칙

- ⛔ 대화로 모은 값은 **확인 카드에서 사람이 확인**해야 실행된다. 실행 경로는 기존 화면과 같다(세션 설계 = `planned` 세션 생성 · 공개 = `guardian_shares` 생성/철회).
  공개 게이트(확정 + 보호자 문장 승인)·철회 권한(`share_revoke`)은 서버가 판정하고, 대화창은 미리 이유를 알린다.
- 공개는 항목의 **요약 줄**만 켠다(일지 = 보호자 문장, 대화 = 요약). 사진·AI 분석 세부 공개는 공개 관리 화면. 비공개 전환은 그 항목에 걸린 공개를 **모두** 내린다(공개 관리 화면과 같다).
- 일지 확정·위기 확인은 대화창에서 하지 않는다 — 확인할 일은 해당 화면 링크로 안내한다.
- 조회 실패를 '없음'으로 말하지 않는다(확인할 일·메시지·공개 항목).
- 시안의 요양보호사 이름·사진·'지금 접속 중이에요'는 보호자가 읽을 데이터가 없어 넣지 않았다(자리표시자 금지) — '담당 요양보호사'로 적는다.

## 후속 — 요양보호사 자유 입력 (2026-11-04 사용자 요청)

- 요청: 버튼만이 아니라 "OOO 어르신 세션 대신 설계하는데, 대화 주제는 가족으로 하자." 처럼 **직접 타이핑해도** 기능하게. LLM 없이 가능한지.
- 결정(질문 답변): ① **규칙 + 나중에 LLM 보조** — 지금은 규칙만, 해석 결과 모양(`CaregiverCommand`)을 고정해 `CommandInterpreter` 로 LLM 을 끼울 자리를 둔다.
  ② **주제 → 키워드 + 제목 제안**('<주제> 이야기', 확인 카드에 보인다 · 목표는 따로 묻는다). ③ **말하지 않은 값 = 모달 기본값**(목표 시간 = 기관 설정 5~10 · 기록일 = 오늘 · 피해갈 내용 = 기관 기본값) — 필수인 어르신·제목·목표만 되묻는다.
- 규칙(core `assistant-command.ts`):
  - 꼬리표 + 조사(은·는·을·를·:) — 제목·목표·주제·나눌 이야기·피해갈 내용·키워드·목표 시간·날짜. 값은 다음 꼬리표·문장 끝·쉼표(키워드·피해갈 내용은 쉼표 허용)에서 끝나고 끝의 '으로 하자'·'해 줘' 등을 뗀다. 따옴표 값은 그대로.
  - 꼬리표 없는 표현 — 'N분' · 오늘/내일/모레/(이번·다음 주) X요일/M월 D일 · "X 얘기는 피해"(기관 기본값에 **더한다** — '피해갈 내용은 X' 는 그 값으로 **바꾼다**) · "X 이야기로"(주제).
  - 범위 밖 분·50자 넘는 제목·지난 날짜는 값을 넣지 않고 이유를 말한다. 목록에 없는 어르신 이름은 지어내지 않고 알린다. 같은 이름이 여럿이면 고르게 한다.
  - 단계 질문에 답하는 중에는 **꼬리표가 있을 때만** 고치는 말로 읽는다(목표 "10분 동안 웃기" 를 분으로 오해하지 않게). 확인 단계에서는 "7분으로 바꿔" 같은 말도 고치는 말 → 이전 카드를 잠그고 새 카드.
  - 공개: "M월 D일 일지/대화 요약 공개(비공개)" — 날짜는 지난 쪽으로 읽고, 종류·날짜·공개 상태로 하나가 정해지면 그 카드로 바로. 이미 공개 중/공개 전이면 이유를 말하고 후보 칩만 보인다.
  - 답장: 보호자 이름(조직 연결 목록에 있는 것만) + 따옴표/'…라고' 본문 → 스레드가 하나면 답장 카드, 본문이 없으면 그 스레드를 연다. 따옴표 본문 속 낱말('설계' 등)은 업무로 읽지 않는다.
- ✅ 검증: core 379(새 `assistant-command.test.ts` 29 — 사용자 예문 그대로 포함) · `test:assistant`(자유 입력 설계 → 목표만 되묻기 → '7분으로 바꿔' → 저장 값 = 제목 '가족 이야기'·키워드 ['가족']·오늘·피해갈 '병원' · 날짜로 일지 공개 카드 · 따옴표 답장 카드 · 모두 확인 전 무전송) ·
  '이전 카드 잠금' 제거 변형이 스모크에서 실패함을 확인 · 전체 typecheck·lint·`check:copy`·`check:bom`·`check:web`(디자인 213 · 라우트 67/67). DB 변경 없음.
- 한계(규칙 기반): 꼬리표·정해진 표현 밖의 말("다음에 할 땐 좀 짧게")은 읽지 못하고 예시와 함께 다시 묻는다 — 이 부분이 나중 LLM 보조의 대상이다.
