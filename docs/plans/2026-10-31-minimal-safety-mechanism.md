# 최소 안전 검사 보완 — 2026-10-31

## 조사 근거와 적용 범위
- ElliQ 공식 약관: 응급 서비스가 아니며 실시간 위험 감지를 보장하지 않는다. 고령자 동반 서비스의 경계 참고. https://elliq.com/pages/elliq-tou
- Wysa Gateway: 위기 신호 검사와 돌봄팀 알림을 공개한다. 정신건강 서비스이므로 기억온과 동일 제품이 아니며 내부 알고리즘·임계치는 공개 자료로 확인하지 못했다. https://www.wysa.com/gateway
- Verily VBHSF 연구: 임상의가 라벨링한 모의 메시지 등에서 전용 텍스트 분류기를 평가했다. 한국어 어르신 실음성 검증이나 기억온의 성능 근거가 아니다. https://arxiv.org/abs/2510.12083

이 자료는 구조 선택의 참고이며 아래의 한국어 규칙을 업계 표준이나 임상 검증된 판정으로 주장하지 않는다.

## 최종 적용 메커니즘
음성 → 기존 Gemini 전사 → 기존 결정론 검사 → 위기·급성 고통이면 기존 중단·사건 저장 → DB 트리거의 담당자 웹 알림. AI 출력은 기존 검사 통과 뒤에만 TTS로 전달한다.

✅ 기존 중단 기준·휴식/거부 마무리·재개 정책·3초 무음 경계 유지.
✅ 명시적 호흡 불가 표현 4개 보완: 숨을 쉴 수 없다 / 숨을 쉴 수가 없다 / 호흡이 안 된다(돼) / 호흡을 못 한다.
✅ 원문 철자를 유지하고 감지 표현 위치 중심으로 최대 120자 근거 저장. 중계가 먼저 끝 120자로 자르는 문제 제거.
✅ 중계 로그에 safety_detected 및 safety_record_result(stored/failed) 추가. 새 로그에 원문·범주·인물·키워드 없음. 기록 성공은 웹 수신 성공을 뜻하지 않는다.

추가 외부 호출·의존성·DB 스키마·새 중단 단계 없음. 기존 명확한 위험 판정을 모델이 취소하는 경로 없음.
