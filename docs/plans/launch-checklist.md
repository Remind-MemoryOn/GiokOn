| A5 | 위기 키워드(시험 시나리오) | 즉시 종료 · 감독 화면 강조 · 요양보호사 휴대폰 푸시(성함·발화 없음) |

| A7 | 10분 경과 | 마무리 후 세션이 끝난다(연장 불가) |
| A8 | 한 요양보호사가 기기 5대째 시작 | 5번째는 막히고 이유가 보인다 |
| A9 | 기술에 익숙하지 않은 50~60대가 설명 없이 1회 | 선택 → 설계 확인 → 시작 → 종료 후 확인까지 끝낸다 |
| A10 | 태블릿(iPad·Android)에서 두 모드 | 화면이 깨지지 않는다 · 글자·버튼이 충분히 크다 |
