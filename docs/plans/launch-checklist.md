## 3. 파일럿 — 개시 전 사람이 눌러 볼 것

**웹**
| # | 할 일 | 참이어야 하는 것 |
|---|---|---|
| P1 | 관리자가 초대 코드 발급 → 직원이 그 코드로 가입 | 승인 전에는 어떤 기록도 안 보인다 |
| P2 | 합류 승인 → 한 명을 사회복지사로 지정 | 같은 기관 전체 어르신이 보인다 · 자기 역할은 못 바꾼다 |
| P3 | 두 브라우저로 감독 화면 → 한쪽에서 일시정지 | 다른 쪽에 2초 안에 반영 · 개입 기록이 남는다 |
| P4 | 앱 세션 종료 | 일지 초안이 버튼 없이 "확인 대기"에 올라온다(실패면 "생성 실패" + 재시도) |
| P5 | 위임 없는 요양보호사로 확정 시도 | 확정 불가 · 사회복지사는 가능 · 위임을 켜면 가능 |
| P6 | 확정 후 한 칸 수정 | 사유를 묻고, 이력에 누가·언제·무엇이 남는다 |
| P7 | 보호자 문장 승인 전 공개 → 승인 후 공개 | 승인 전 거부 · 보호자에게는 보호자 문장만 보인다 |
| P8 | 공개 철회 | 보호자 화면에서 바로 닫힌다 |
| P9 | 보호자 대화 관찰 리포트 | 점수·판정 표현 0건 · 하단 고정 문구 |
| P10 | 어르신 동의 철회 | 새 세션 시작이 막힌다 |

**앱 (실기기)**
| # | 할 일 | 참이어야 하는 것 |
|---|---|---|
| A1 | 중계 주소를 비운 빌드로 시작 | 시작이 막히고 이유가 보인다 |
| A2 | 어르신 표시 모드에서 화면을 여기저기 누른다 | 세션이 꺼지거나 넘어가지 않는다 |
| A3 | 제스처/PIN 없이 요양보호사 모드로 돌아가 본다 | 돌아갈 수 없다 |
| A4 | 감독 화면에서 일시정지·재개 | "잠시 쉬어요" + 마이크 정지 · 재개하면 이어진다 |
| A5 | 위기 키워드(시험 시나리오) | 즉시 종료 · 감독 화면 강조 · 요양보호사 휴대폰 푸시(성함·발화 없음) |
| A6 | "그만할래" | 짧게 마무리하고 끝난다 · 감독 화면에 알림 |
| A7 | 10분 경과 | 마무리 후 세션이 끝난다(연장 불가) |
| A8 | 한 요양보호사가 기기 5대째 시작 | 5번째는 막히고 이유가 보인다 |
| A9 | 기술에 익숙하지 않은 50~60대가 설명 없이 1회 | 선택 → 설계 확인 → 시작 → 종료 후 확인까지 끝낸다 |
| A10 | 태블릿(iPad·Android)에서 두 모드 | 화면이 깨지지 않는다 · 글자·버튼이 충분히 크다 |
