# 시간 기준 대화와 감독 화면 종료

2026-10-28 사용자 승인: 정상 대화의 10회/중계 60턴 종료를 제거하고 서버 목표 시간(최대 10분, 일시정지 포함)을 따른다. 앱 비정상 종료로 남은 세션을 감독 화면에서 종료한다.

- ⏳ 앱 종료 권고·응답/재개 조건과 중계 턴 차단 제거. 안전 판단·거부·위기·시간 상한 유지.
- ⏳ 별도 서버 종료 RPC: 같은 기관 돌봄팀만, 서버 저장 기록 보존, 종료 감사 기록, 중복 호출 안전, 늦은 앱 쓰기 방어. 실제 대화 시간을 알 수 없으면 임의로 채우지 않는다.
- ⏳ 감독 화면 ‘지금 종료 처리’: 진행/일시정지/종료 요청/어르신 마무리 모두 가능. 확인창에서 미저장 기기 내용의 한계 안내. 기존 기기 종료 요청은 유지.
- ⏳ 앱·중계·DB 회귀, 웹 브라우저 성공/실패/취소/종료 요청 후 재처리 검증.
- ⏳ 운영 DB 마이그레이션·웹 배포·중계 배포·새 APK 후 실기기 확인. 코드 검사 성공을 운영 완료로 기록하지 않는다.
