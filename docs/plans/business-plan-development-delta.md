# 사업 기획 반영 개발 실행안

기준: 2026-09-12 사용자 결정. 프로젝트 메모리 SoT는 ../../AGENTS.md, 음성 상세 설계는 voice-ai-personalization.md다. 이 문서는 사업 기획에서 발생한 개발 차이·우선순위·인수 조건을 관리한다. 코드·DB·배포 변경 완료를 의미하지 않는다.

## 확정 사실과 제안 구분

2026-09-13 추가 승인: 서버가 음성 연결과 출력을 통제하는 중계 구조를 개발 기준으로 채택한다. 실행 환경은 미정이다. 계약 정리 → 공통 보안 보강 → 자동 대화·검증 출력·최소 지원·계측의 종단 구현 → 현장 검증 → 유료 도입 → 독립 학습 순으로 진행한다. 상세한 DB 제외 개발 범위는 [N01~N35](non-db-development-backlog.md)에 있으며, DB 의존성이 있는 기능의 배포는 해당 보호 검증을 기다린다. R013 이후 기존 위험 항목을 삭제하거나 문서 변경만으로 해결 처리하지 않는다.

- 팀: 임성훈(기획·개발), 박진우(개발·영업), 고서연(UI/UX·프론트엔드 디자인). 아래 작업 배분은 역할에 따른 제안이다.
- 초기 앱: Gemini Live에 음성을 직접 입력하고 프롬프트로 대화를 설계·진행한다. 응답 텍스트를 검증한 뒤 Clova TTS로 재생한다. 일반 오디오 API 우선·Live 비교용이라는 9월 11일 계획을 대체한다.
- 담당자는 세션을 설계하고 시작·회수·사후 확인을 지원한다. 매 턴 담당자 승인 없는 진행이 목표이며 예외 개입과 실제 단독 사용 범위는 검증해야 한다.
- 일지: 식사·활동·특이사항 등의 자유서술형 기록. 담당자가 원문 포함 여부·구성·왜곡을 확인하고 수정·최종 저장·공개를 결정한다. 법정 양식 전체 지원이 아니다.
- 시설 3곳은 연결된 접점이다. 베타·POC·파일럿 미실시, 발표 1주 후 테스트 예정. 기관별 참여·일정·표본·기간은 미확정이다.
- 장기: 독립 수집·사람 전사·검수 자료로 Whisper 및 Qwen3.5-9B를 각각 특화하고 비교 평가 후 전환한다. Clova 유지. Gemini 참여 세션의 출력·파생 자료는 계약 확인 전 학습에서 제외한다.
- 첫 구매 가설은 생활 소식 작성·공유 부담 감소. 기관 기본 구독+회상 사용량 과금은 추천안이며 99,000/149,000원·포함량·결제 조건은 미확정이다.

## 작업 목록과 인수 조건

모든 체크는 미완료다. 기존 구현 기반이 있다는 뜻과 아래 변경 완료를 구분한다.

### 현장 테스트 전 (D1~D5)

- [ ] D1 / 임성훈·고서연: 매 턴 확인 패널을 전제하지 않는 청취→응답 루프. 긴 침묵·맞장구·어르신 중단·오류 종료·회수 안내를 설계한다. 기존 패널은 예외/담당자 모드로 재검토한다. 인수: 담당자 매 턴 조작 없이 진행하고 중단·지연 응답·재연결 후 과거 응답 오재생이 없어야 한다.
- [ ] D2 / 임성훈·박진우: Live 출력 전사→서버 의미·안전 검증→Clova 재생. 누락·불일치·차단 시 원본 음성을 버리고 검증된 대체 문장/종료로 처리한다. 인수: 검증 전 음성·이중 재생 없음, 회수/취소 후 재생 중지, 최종 텍스트와 재생 근거 일치. Structured Outputs를 Live의 보장으로 전제하지 않는다.
- [ ] D3 / 임성훈: 질문 길이·단서·재확인·주제·휴식 정책과 관찰 근거 기록. 인수: 인지 점수 자동 생성 없음, 타인 생애정보 혼입 없음, 중단 존중 및 모호한 의미 재확인.
- [ ] D4 / 고서연·임성훈: 현재 규칙 초안의 범위를 정확히 표시하고 음성 입력→편집→최종 저장→선별 공개 흐름을 점검한다. 원문과 초안, 관찰 일지와 회상 발화를 구분한다. 인수: 미관찰 사실 생성 없음, 초안 무단 공개 없음, 철회 후 보호자 접근 차단. 신규 LLM 초안을 사용한다면 D6 품질 조건도 통과해야 한다.
- [ ] D5 / 박진우·임성훈: 입력·초안·수정·승인 시각, 담당자 시작/회수/예외 개입 시간, 사용 실패·중단 사유, 공급자 청구 토큰과 TTS 글자 수 계측. 인수: 원문 음성/개인 발화를 일반 분석 로그로 보내지 않으며 미측정은 null, 재시도 중복 집계 방지. 시설별 테스트 범위·동의·책임자·대응 경로 사전 확정.

D1~D5는 기존 보안·동의·실기기 게이트를 대체하지 않는다. R010의 이미 열린 공급자 연결 통제 문제는 서버가 전송·연결 수명을 집행하는 구조 및 실행 환경 설계가 필요하다. 앱 확인 버튼을 없애도 이 문제가 해결되지 않는다. 지원 경로 없는 무인 운영은 테스트 완료로 표시하지 않는다.

### 첫 유료 도입 전 (D6~D8)

- [ ] D6 / 임성훈: 생성형 일지 초안 서버 호출·버전·시간 제한·오류 대체 경로. 입력 사실과 생성 초안을 구분해 저장하고 누락·부정 반전·미관찰 내용·수정 시간으로 규칙 기준선과 비교한다. 모델 선정은 미확정이며 화면의 AI 표기만으로 LLM 연동 완료라 하지 않는다.
- [ ] D7 / 박진우·임성훈: 기관별 실제 사용·원가 대시보드, 포함량/상한·추가 사용 동의·요금 확정 후 구독/결제/청구. 토큰 재과금·Live 원본 음성 생성·Clova Application별 기본료·지원비를 반영한다. 한도 도달 시 안전한 종료·기록 보존 필요. 무제한·자동 초과 결제를 기본값으로 두지 않는다.
- [ ] D8 / 박진우·고서연: 기존 방식과 동일 업무 비교, 담당자 교육·도입·문의 처리. 구매 의향/참여 합의/계약/결제를 분리하고 반복 사용·갱신 여부를 측정한다. AI 대화 시간을 그대로 인력 절감으로 환산하지 않는다.

### 고객·데이터 확보 후 (D9~D11)

- [ ] D9: 별도 선택 학습 동의·독립 사람 진행 대화 수집·사람 전사·전문가 검수·출처/권리/철회/데이터셋 계보. 운영 데이터가 자동으로 학습 자료가 되는 구조 금지.
- [ ] D10: Whisper 특화와 Qwen3.5-9B SFT/LoRA, 화자별 분할·의미/안전/지연/총원가 비교. Ollama는 추론 후보이며 학습 도구가 아니다. 초기 음성 경로 대비 억양·휴지 정보 손실도 평가한다.
- [ ] D11: 기관별 양식→기존 업무관리 시스템 연동/병행→검증된 기능 대체. 케어포 API·제휴는 미확보다. 청구·인력·일정·평가 전체 대체는 별도 범위 산정 후 추진한다.

GS 인증은 품질·절차·시험 준비 계획이고 취득 실적이 아니다. EMR·임상·의료 용도는 사용 목적·협력·권리·심의·예산을 갖춘 별도 장기 과제다. 엑시트·시장·팀 구성만으로 신규 기능을 추가하지 않는다.
