# 파트별 남은 일

파일럿(한 시설 시험 운영)까지 남은 일을 네 부분으로 나눴습니다. 순서와 자세한 내용은
[파일럿 개발 계획](../plans/pilot-development-plan.md)에 있습니다.

## 데이터 (DB — 모든 기록이 저장되는 곳)

- **권한 다시 짜기(가장 먼저)** — 지금은 "담당 요양보호사만" 볼 수 있는데, 교대 근무 때문에 **같은 시설 직원이면 함께** 볼 수 있어야 합니다. 사회복지사·센터장 역할도 새로 만듭니다.
- **직원 합류** — 초대 코드로 같은 시설에 들어오고, 관리자가 승인해야 기록이 보이게 합니다.
- **프로그램 일지** — 공식 서식에 맞는 기록 칸을 만들고, 기존 "요양일지" 기록은 지웁니다. 사람만 확정할 수 있게 막습니다.
- **대화 단계와 원격 제어** — 대화가 지금 어느 단계인지(인사 → 옛이야기 → 마무리), 누가 멈추게 했는지 남깁니다.
- **알림과 사용 기록** — 휴대폰 알림을 보낼 준비, "몇 번 했고 시간을 얼마나 아꼈나"를 셀 기록을 남깁니다.

## 앱 (태블릿·휴대폰)

- **어르신 화면 따로 만들기** — 어르신은 사진·자막·"말하는 중" 표시만 보고, 누를 버튼이 없게 합니다. 지금은 요양보호사용 버튼이 섞여 있습니다.
- **요양보호사 화면으로 돌아가기** — 숨은 동작이나 비밀번호로만 돌아갈 수 있게 합니다.
- **멈춤 신호 받기** — 요양보호사가 멀리서 멈추면 "잠시 쉬어요"를 띄웁니다.
- **휴대폰 알림 받기** — 위험한 말이 나오면 요양보호사에게 알림이 가게 합니다.
- **옛 연결 방식 지우기**, **글씨·버튼 크게**, **처음 쓰는 분을 위한 안내**.

## 웹 (요양보호사·보호자용 웹사이트)

- **프로그램 일지 화면** — 자동으로 만들어진 초안을 확인하고, 고치고, 확정합니다. 확정 후 고치면 이유를 남깁니다.
- **지켜보기 화면** — 진행 중인 대화 최대 4개를 휴대폰으로도 보고, 멈추기·다시 시작·끝내기를 합니다.
- **시설 설정** — 누가 확정·공개·승인할 수 있는지 고르고, 직원 역할을 정하고, 초대 코드를 만듭니다.
- **동의 화면**, **가입할 때 시설 합류하기**, **어르신 등급 입력**.
- **보호자 화면 말투 바꾸기** — "오늘의 이야기"처럼 있었던 일만 쉬운 말로 보여 줍니다.

## 앱과 웹 연결 (가운데서 이어 주는 부분)

- **대화를 이어 주는 서버** — 멈춤 신호와 대화 단계를 앱에 전하고, 위험한 말은 **바로** 기록합니다. 대화를 10분으로 제한합니다.
- **일지 초안 만들기** — 대화가 끝나면 자동으로 초안을 만들어 "확인 대기"에 올립니다.
- **알림 보내기** — 휴대폰으로 알림을 보냅니다. 알림에는 어르신 이름이나 대화 내용을 넣지 않습니다.
- **쓰지 않는 옛 코드 정리** — 예전 규칙 방식 대화 코드를 지웁니다.

## 개발 말고 필요한 것

- 서버를 올릴 곳 정하기, 알림 서비스 가입, 로그인 연결 설정
- 동의서 법률 검토, AI 서비스 유료 계약
- 실제 기기(태블릿·휴대폰)로 시험해 보기 — [출시 점검표](../plans/launch-checklist.md)
