# 파트별 남은 일

파일럿(한 시설 시험 운영)까지 남은 일을 네 부분으로 나눴습니다. 순서와 자세한 내용은
[파일럿 개발 계획](../plans/pilot-development-plan.md)에 있습니다.

## 데이터 (DB — 모든 기록이 저장되는 곳)

- ✅ **권한 다시 짜기(가장 먼저)** — 지금은 "담당 요양보호사만" 볼 수 있는데, 교대 근무 때문에 **같은 시설 직원이면 함께** 볼 수 있어야 합니다. 사회복지사·센터장 역할도 새로 만듭니다.
  (2026-09-24: ✅ 같은 시설 직원이면 담당이 아니어도 기록을 보고 대화를 진행 · ✅ 역할 두 개 추가 · ✅ 시설별 권한표 · ✅ 관리자·센터장의 역할 지정 — 실제 서버 반영 완료 2026-09-24. 동의 기록·보호자 공개·삭제는 지금처럼 담당·관리자만. 화면은 웹 담당)
- 🔶 **직원 합류** — 초대 코드로 같은 시설에 들어오고, 관리자가 승인해야 기록이 보이게 합니다. (2026-09-24: ✅ 데이터 쪽 완성 — 실제 서버 반영 완료 2026-09-24. ⏳ 가입·승인 화면은 웹 담당)
- **프로그램 일지** — 공식 서식에 맞는 기록 칸을 만들고, 기존 "요양일지" 기록은 지웁니다. 사람만 확정할 수 있게 막습니다.
- ✅ **대화 단계와 원격 제어** — 대화가 지금 어느 단계인지(인사 → 옛이야기 → 마무리), 누가 멈추게 했는지 남깁니다. 한 사람이 동시에 4개까지만 진행하게 막습니다. (2026-09-24, 실제 서버 반영 완료 2026-09-24)
- 🔶 **알림과 사용 기록** — 휴대폰 알림을 보낼 준비, "몇 번 했고 시간을 얼마나 아꼈나"를 셀 기록을 남깁니다. (2026-09-24: ✅ 알림 받을 기기 등록 칸 — 실제 서버 반영 완료 2026-09-24 · ⏳ 사용 기록)

## 앱 (태블릿·휴대폰)

- ✅ **어르신 화면 따로 만들기**(2026-09-24) — 대화를 시작하면 바로 어르신 화면으로 넘어갑니다. 어르신은 질문 글자와 "말하는 중" 표시만 보고, 누를 버튼이 없습니다.
- ✅ **요양보호사 화면으로 돌아가기**(2026-09-24) — 구석의 작은 '선생님' 버튼을 누르고 **PIN 4자리**를 넣어야 돌아갑니다. PIN은 설정 화면에서 바꿉니다.
- ✅ **옛 연결 방식 지우기**(2026-09-24) — AI 목소리는 이제 검사를 거치는 한 길로만 나옵니다. 대화 기록 저장 순서도 정리했습니다.
- ✅ **멈춤 신호 받기**(2026-09-24) — 요양보호사가 멀리서 멈추면 마이크를 끄고 "잠시 쉬어요"를 띄웁니다. 멀리서 다시 시작하면 2초 안에 저절로 이어집니다. 멀리서 멈춘 것은 기기 앞에서 풀 수 없습니다. (실제 서버 DB 반영 완료 — 앱 재빌드·중계 배포 전)
- ✅ **휴대폰 알림 받기**(2026-09-24) — 직원이 로그인하면 알림을 허락받고 이 기기를 등록합니다. 로그아웃하면 등록을 풉니다. 실제 알림은 "알림 보내기"(연결 파트)가 끝나고, 앱을 새로 빌드해야 옵니다.
- ⏳ **처음 쓰는 분을 위한 안내** — 이번에는 빼고 나중에 합니다.

## 웹 (요양보호사·보호자용 웹사이트)

- **프로그램 일지 화면** — 자동으로 만들어진 초안을 확인하고, 고치고, 확정합니다. 확정 후 고치면 이유를 남깁니다.
- **지켜보기 화면** — 진행 중인 대화 최대 4개를 휴대폰으로도 보고, 멈추기·다시 시작·끝내기를 합니다.
- **시설 설정** — 누가 확정·공개·승인할 수 있는지 고르고, 직원 역할을 정하고, 초대 코드를 만듭니다.
- **동의 화면**, **가입할 때 시설 합류하기**, **어르신 등급 입력**.
- **보호자 화면 말투 바꾸기** — "오늘의 이야기"처럼 있었던 일만 쉬운 말로 보여 줍니다.

## 앱과 웹 연결 (가운데서 이어 주는 부분)

- 🔶 **대화를 이어 주는 서버** — 멈춤 신호와 대화 단계를 앱에 전하고, 위험한 말은 **바로** 기록합니다. 대화를 10분으로 제한합니다. (2026-09-24: ✅ 멈춤 신호·대화 단계 전하기 · ⏳ 위험한 말 바로 기록 · ⏳ 10분 제한 · ⚠️ 실제 서버에는 데이터 변경을 먼저 반영한 뒤 이 서버를 올려야 합니다)
- **일지 초안 만들기** — 대화가 끝나면 자동으로 초안을 만들어 "확인 대기"에 올립니다.
- **알림 보내기** — 휴대폰으로 알림을 보냅니다. 알림에는 어르신 이름이나 대화 내용을 넣지 않습니다.
- ✅ **쓰지 않는 옛 코드 정리**(2026-09-24) — 예전 규칙 방식 대화 코드를 지웠습니다(웹이 아직 쓰는 일지 초안 함수 하나만 남음).
- ⏳ **옛 연결 길 서버에서 막기** — 앱 코드는 지웠지만, 서버가 중계를 거치지 않은 요청에도 AI 연결 열쇠를 내주는 길은 아직 열려 있습니다.
