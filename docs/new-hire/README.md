# 새로 합류하신 분께

기억온 팀에 오신 것을 환영합니다. 이 폴더는 **처음 오신 분이 프로젝트를 빠르게 이해하도록** 쉬운 말로 짧게 정리한 것입니다.
자세한 내용은 다른 문서에 있으니, 여기서는 큰 그림만 잡으시면 됩니다.

## 자주 나오는 말

| 말 | 뜻 |
|---|---|
| 요양원 | 어르신이 머물며 지내는 시설. 직원들이 교대로 일한다 |
| 주간보호센터 | 어르신이 낮에만 다니는 시설 |
| 요양보호사 | 현장에서 어르신을 돌보는 분. 이 서비스의 주 사용자 |
| 사회복지사 · 센터장 | 기록을 최종 확인하고 권한을 정하는 분 |
| 보호자 | 어르신의 가족 |
| 인지활동 프로그램 | 어르신의 기억과 생각을 돕는 활동. 시설이 꼭 해야 하는 일이다 |
| 회상 대화 | 어르신의 옛 이야기(고향·직업·가족)를 나누는 대화 |
| 프로그램 일지 | 프로그램을 했다는 공식 기록. 이 서비스가 자동으로 초안을 만든다 |
| 연대기 | 어르신 한 분의 인생 이야기를 정리한 기록 |
| 파일럿 | 한 시설에서 먼저 실제로 써 보는 시험 운영 |
