# 지금 진행 상황 (2026-09-24 기준)

## 큰 흐름

- **2026년 4~6월** — 학교 과제로 시작. 어르신과 AI가 옛 이야기를 나누는 앱을 만들었습니다.
- **7~8월** — 현장 인터뷰를 반영해 요양보호사용 웹과 보호자용 웹을 붙였습니다. 로그인, 기관·역할, 보호자 연결, 공개 관리가 이때 생겼습니다.
- **9월 초** — 출시 전 점검에서 나온 보안 문제를 고치고, AI 목소리가 검사를 거친 문장만 나오도록 대화 구조를 바꿨습니다.
- **9월 23일** — 기획이 바뀌었습니다. "요양보호사 업무를 전반적으로 돕는 도구"에서
  **"AI가 인지활동을 진행하고 공식 기록 초안을 자동으로 남기는 도구"** 로 방향을 좁혔습니다.
- **지금** — 바뀐 기획에 맞춰 계획을 새로 세웠고, **한 시설에서 시험 운영(파일럿)** 할 수 있는 수준을 목표로 개발을 시작하는 단계입니다.

## 이미 되어 있는 것

- 요양보호사 로그인, 어르신 등록과 인생 이야기(연대기) 관리
- 앱에서 AI와 어르신의 음성 대화, 대화 기록 저장, 대화 분석
- 웹에서 대화 기록·분석 보기, 보호자 연결과 공개·철회
- 동의가 없으면 대화를 막는 장치, 위험한 말을 알아채는 장치
- 여러 차례의 보안 점검과 수정

## 이번에 정해진 것 (2026-09-24)

- 새로 만드는 화면은 **지금 디자인과 최대한 똑같이** 만든다. 새 디자인이 오면 그때 바꾼다.
- 어르신이 "그만할래"라고 하면 **짧게 인사하고 마무리**한다. 위험한 말에는 **바로 멈춘다**.
- 대화 한 번은 **최대 10분**, 요양보호사 한 명은 **최대 4대**까지 동시에 지켜본다.
- **태블릿에서도** 앱을 쓸 수 있게 했다.

## 파일럿 개발에서 끝난 것 (2026-09-24)

- **앱**: 옛 AI 연결 방식을 지웠고(목소리는 검사를 거친 한 길로만), 어르신 화면을 따로 만들었으며, 요양보호사 화면으로 돌아갈 때 PIN을 묻습니다.
  대화 기록 저장 순서도 정리했습니다. 자세한 것은 [남은 일](03-remaining.md)의 ✅ 표시를 보세요.

## 시작 전에 꼭 풀어야 하는 것

- 직원이 **같은 시설 계정에 함께 들어올 방법**이 아직 없습니다(지금은 가입할 때마다 새 시설이 생깁니다).
- ~~어르신 **동의를 화면에서 주고 거두는** 기능이 없습니다.~~ ✅ 2026-09-24 웹에 생겼습니다(진우 님 브랜치, 합치기 전). 동의는 이제 4가지이고, 새 서버 규칙은 이미 켜져 있어 **합치기 전까지 새로 등록한 어르신은 대화를 시작할 수 없습니다.**
- 위험한 말이 나와도 **대화가 끝날 때에야** 기록돼서, 바로 알림을 보낼 수 없습니다.
- 옛 방식으로 AI에 바로 연결할 수 있는 길이 **서버에** 아직 열려 있어 막아야 합니다(앱 쪽 코드는 2026-09-24 지웠습니다).

## 다른 분들이 답을 주셔야 하는 것

- 이 방식(사람이 계획·감독 + AI가 진행)이 공식 프로그램으로 인정되는지 — 공단 확인
- 동의서 문구, 해외 서비스 사용 동의 — 법률 검토
- 보호자에게 보여 주는 요약이 의료기기 규제에 걸리지 않는지 — 규제 확인
