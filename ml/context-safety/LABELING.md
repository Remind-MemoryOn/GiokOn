# 라벨 규약 — 전사 문맥 분류기 (v1.0 · 2026-11-14)

> **상태: v1.0 고정(2026-11-14 사용자 확정).** 축 7개와 각 축의 값을 확정했다. 인계서 §5.1·기획 §7.3 에서 바꾼 곳은 **〔확정 변경〕** 으로 표시했다.
> 값을 바꾸려면 `labelGuideVersion` 을 올리고 영향받는 예시를 다시 검수한다(§6).
> 라벨은 "직원 확인이 필요한 신호"를 가리는 데 쓴다. 진단·임상 판단이 아니다. 라벨 이름에 임상 용어를 쓰지 않는다.

## 1. 무엇에 라벨을 붙이나 — 입력 단위

- **대상 턴**: 어르신의 한 턴 전사(`target`). 라벨은 **이 턴에만** 붙인다.
- **문맥**(`context`): 직전 AI 질문 + 최근 어르신 발화 1~2턴. 해석을 돕는 데만 쓰고, 문맥 속 발화 자체에는 라벨을 붙이지 않는다.
  - 문맥에 나온 위험 발화가 대상 턴에서 반복되지 않으면 대상 턴의 라벨이 아니다.
    단, 대상 턴이 그 발화를 이어 받으면("네, 그래요 지금도") 대상 턴의 라벨이다.
- 최대 길이는 아직 정하지 않았다(지연 예산을 보고 S5 에서 정한다).

## 2. 핵심 원칙

1. **내용은 문자 그대로 붙이고, 주체·시점·표현 방식은 따로 붙인다.** "옛날에 죽고 싶었던 적도 있어요" → 내용 `crisis_appeal` + 시점 `past`.
   "위기 내용이지만 과거·인용·부정·관용"이라는 조합을 정책이 따로 다루기 때문이다(인계서 §5.7 진리표).
   - 〔확정 변경 2026-11-14〕 **위기 어구(죽다·숨을 못 쉬다·맞다 등)가 관용·과장으로 쓰여도 문자 그대로의 내용을 붙이고 `mode=idiom` 으로 표시한다**("죽겠다 배고파서" → `crisis_appeal`·`self_harm` + `idiom`).
     위기 어구가 아닌 정서 관용구("가슴이 아파요"·"속이 터져")는 실제 뜻으로 붙이고 `mode=idiom` 만 표시한다(→ `sadness_grief`·`acute_distress` 등).
     실제 뜻으로 붙이는 방식(→ `daily`)은 채택하지 않았다. 인계서 진리표의 "위기지만 과거·인용·부정·관용" 행(Q4)과 구조를 맞추기 위해서다 — Q4 에서 정할 동작이 관용 문장에도 적용된다.
2. **여러 개 가능**: 내용·위기 범주는 다중 라벨이다. 휴식 요청과 고통이 함께 나오면 둘 다 붙인다. 하나로 줄이지 않는다.
3. **모르면 불명**: 근거 없이 추측하지 않는다. 확신이 없으면 그 축은 `unknown` 이다. 이것은 실패가 아니라 정상 라벨이다.
4. **안전 쪽으로 기울지 않는다.** 위험해 보인다고 `present`·`self`·`direct` 를 고르지 않는다. 문장에 근거가 없으면 `unknown` 을 쓴다.
   (안전 쪽 처리는 정책 함수(S4)의 일이다. 라벨이 기울면 기준선과 분류기 평가가 모두 왜곡된다.)
5. **규칙 사전을 보고 라벨을 붙이지 않는다.** 규칙 결과와 비교하는 것이 평가의 목적이다.

## 3. 축과 값

### 3.1 내용 `content` (다중)

| 값 | 뜻 | 예 | 반례(이 값이 아님) |
|---|---|---|---|
| `crisis_appeal` | 자해·죽음 생각, 신체 응급, 학대·폭력 피해의 언급 | "숨이 안 쉬어져요" · "아들이 때려요" | "죽 끓여 먹었어요"(음식) |
| `acute_distress` 〔확정 변경〕 | 견디기 어려운 고통의 호소(정서·신체를 가리지 않음, 응급은 아님) | "너무 힘들어서 못 견디겠어요" | "그땐 참 힘들었지"(회상 속 슬픔 → `reminiscence`+`sadness_grief`) |
| `sadness_grief` 〔확정 변경〕 | 슬픔·그리움·애도·서운함. **정상 반응** | "영감 생각하면 마음이 아파요" | "살기 싫어요"(→ `crisis_appeal`) |
| `physical_discomfort` 〔확정 변경〕 | 응급이 아닌 신체 불편 | "무릎이 좀 쑤셔요" · "좀 피곤하네" | "가슴이 조여요"(→ `crisis_appeal`/`medical_emergency`) |
| `refusal` | 질문·대화를 거부 | "그런 얘기 하기 싫어요" · "날 좀 내버려 둬요" | "싫어하는 음식은 오이야"(일상) |
| `rest_request` | 쉬자·그만하자는 요청 | "오늘은 그만할래요" | "그만 좀 먹으라고 하셨지"(회상 속 다른 뜻) |
| `reminiscence` | 과거 경험 이야기 | "어릴 때 숨바꼭질 많이 했지" | |
| `daily` | 지금의 일상·잡담 | "점심은 국수 먹었어요" | |
| `confusion` | 질문을 이해 못 함·지금 상황을 혼동 | "여기가 어디예요?" · "뭐라고요?" | |
| `unknown` | 내용을 정할 수 없음(전사가 깨짐 등) | "그 거… 저…" | |

- 〔확정 변경〕 인계서의 "정서적 고통" 하나를 `acute_distress`·`sadness_grief` 로 나눴다. 이유: ① 애도는 정상 반응이라 D3(분류기 단독 적중 → 일시정지)의 대상이 되면 안 된다.
  ② 규칙의 `ACUTE_DISTRESS`(즉시 종료)·`GRIEF`(계속)와 짝을 맞춰야 S2 기준선을 범주별로 비교할 수 있다.
- 〔확정 변경〕 `physical_discomfort` 추가: 응급과 비응급의 경계를 분류기가 배우게 하려면 비응급 쪽 이름이 필요하다. 없으면 `daily` 로 흩어진다.
- 답답함·짜증("속이 터져, 손주가 말을 안 들어서")은 따로 값을 두지 않고 `daily` + `mode=idiom` 으로 붙인다(2026-11-14 사용자 확정 — 대응 대상이 아니다).
- `unknown` 은 다른 값과 함께 쓰지 않는다.

### 3.2 위기 범주 `crisisCategory` (다중)

`self_harm`(자해·죽음 생각) · `medical_emergency`(신체 응급) · `abuse`(학대·폭력 피해) · `none` · `unknown`.
기존 `CrisisCategory` 3종과 이름이 같다.

- 내용에 `crisis_appeal` 이 **있으면** 하나 이상의 범주(또는 `unknown`). **없으면** `none` 하나만.
- `medical_emergency` 경계: 지금 숨·가슴 조임/짓눌림·쓰러짐·의식·마비·심한 출혈·갑작스럽고 극심한 통증. 가벼운 통증·피로는 `physical_discomfort`.
  "가슴이 아파요" 하나만 있고 문맥이 없으면 신체인지 정서인지 정할 수 없다 → §5 의 해석 가능성 `insufficient` 와 후보 병기.

### 3.3 주체 `subject`

`self`(어르신 본인) · `other`(다른 사람의 경험·말) · `unknown`.
- 다른 사람이 어르신에게 한 행동은 피해자가 본인이므로 `self`("며느리가 밥을 안 줘요" → `self`, `abuse`).
- 다른 사람의 말을 옮기면 `other`("할아버지는 그만하자고 하셨어요").

### 3.4 시점 `tense`

`present`(지금·요즘 계속) · `past`(끝난 과거) · `future`(앞으로·계획) · `unknown`.
- "요즘 자꾸 죽고 싶어요" → `present`. "옛날엔 죽고 싶었지" → `past`. "그러다 죽으면 어떡해" → `future`.
- 과거 이야기에 지금의 감정이 붙으면("그 생각하면 지금도 마음이 아파") 그 감정의 시점 = `present`.

### 3.5 표현 방식 `mode`

`direct`(직접 호소) · `quote`(남의 말 인용) · `hypothetical`(가정·만약) · `negated`(명시 부정) · `idiom`(관용·과장) · `unknown`.
- `negated`: "죽고 싶다는 생각은 안 해요". **부정이 문장 뒤에 붙어도**("죽고 싶… 은 아니고") 대상 턴 전체로 판단한다.
- `idiom`: "죽겠다 배고파서" · "속이 터져" · "가슴이 아파요"(회상 맥락의 정서 관용구).
- 둘 이상이 겹치면 **가장 안전에 무거운 언급**(§4)의 방식을 붙인다.

### 3.6 대화 의사 `intent`

`continue`(계속) · `switch`(다른 이야기로) · `rest`(쉬고 싶음) · `end`(끝내고 싶음) · `unknown`.
- 어르신 **본인의 지금** 대화 의사다. 인용 속 "그만하자"는 의사가 아니다.
- 말에 의사가 드러나지 않으면 `unknown`(대부분의 일상 발화). 이야기를 이어 가는 것만으로 `continue` 를 붙이지 않는다 — "더 얘기할게요"처럼 드러날 때만.

### 3.7 해석 가능성 `interpretability`

`sufficient`(정하기 충분) · `insufficient`(정보 부족 — 문장이 짧거나 끊김) · `conflict`(문맥과 대상 턴이 서로 반대) · `out_of_scope`(어르신 발화가 아님 — TV·다른 사람 목소리로 보임 등).
- `insufficient`·`conflict` 일 때도 다른 축은 할 수 있는 만큼 붙인다(후보가 둘이면 내용에 둘 다).

## 4. 여러 언급이 섞인 문장 — 안전상 무게 순서

주체·시점·표현 방식은 한 값만 붙는다. 한 턴에 여러 언급이 있으면 다음 순서로 **가장 무거운 언급**을 기준으로 붙인다.

`crisis_appeal` > `acute_distress` > `rest_request`·`refusal` > `physical_discomfort` > `confusion` > `sadness_grief` > `reminiscence`·`daily`

예: "옛날에도 힘들었는데 지금은 숨이 차서 말을 못 하겠어요" → 내용 `reminiscence`·`crisis_appeal`, 기준 언급 = 숨참 → `self`·`present`·`direct`.

## 5. 어려운 경계 사례

| 문장(대상 턴) | 라벨 | 이유 |
|---|---|---|
| 가슴이 아파요.(문맥 없음) | `crisis_appeal`+`sadness_grief`, `medical_emergency`, `self`, `present`, `unknown` 방식, `insufficient` | 신체·정서를 가를 근거 없음 |
| (AI: 돌아가신 어머님 얘기) 그 생각하면 가슴이 아파요. | `sadness_grief`+`reminiscence`, `none`, `self`, `present`, `idiom`, `sufficient` | 정서 관용구(D5) — 위기 어구가 아니므로 실제 뜻 |
| 지금 가슴이 아파서 숨이… | `crisis_appeal`, `medical_emergency`, `self`, `present`, `direct`, `insufficient` | 끊겼지만 현재 신체 호소 |
| 죽고 싶다는 생각은 안 해요. | `crisis_appeal`, `self_harm`, `self`, `present`, `negated` | 규칙은 의도적으로 위기 유지 — 라벨은 사실대로 |
| 숨바꼭질하다 숨을 못 쉴 만큼 웃었지. | `reminiscence`+`crisis_appeal`, `medical_emergency`, `self`, `past`, `idiom` | 회상 속 과장. 위기 어구라 문자 그대로 붙인다 |

## 6. 검수 절차

1. 작성: 작성자가 대상 턴·문맥·**작성 의도 라벨**(`labelsByAuthor`)을 쓴다.
2. 검수: 검수자 2명이 **작성자 라벨과 서로의 라벨을 보지 않고** 각자 붙인다(`reviews[]`).
3. 판정: 축별로 두 검수자가 같으면 그 값이 `final`. 하나라도 다르면 그 예시는 `status=disputed` — 학습·평가에 쓰지 않는다.
4. 재검토: 불일치 예시는 두 사람이 이 규약을 근거로 논의한다. 합의하면 `final` 을 채우고 사유를 `notes` 에 적는다.
   합의가 안 되면 `status=excluded` 로 둔다(지우지 않는다 — 규약 개정 근거).
5. 규약이 바뀌면 `labelGuideVersion` 을 올리고, 영향받는 예시를 다시 검수한다.

라벨 출처를 섞지 않는다: `labelsByAuthor`(작성자 의도) · `reviews[].labels`(검수자 판단) · `final`(검수 합의). 학습·평가는 `final` 만 쓴다.
