# apps/web 작업 지침은 `AGENTS.md` 에 있다

> 📌 **이 파일은 포인터다. 내용을 여기에 쓰지 말 것.**

웹 작업 지침의 단일 소스(SoT) = **[`apps/web/AGENTS.md`](./AGENTS.md)**.

`apps/web` 파일을 건드리기 전에 그 문서를 읽는다. 웹에만 해당하는 규칙이 전부 거기 있다 —
앱 경계(어르신 음성 대화는 웹에 없다) · **디자인 SoT 와 재디자인 금지** · 기능 델타 ·
상태·데이터 규칙(세션 `planned`/`active`/`ended` 구분, 공개 항목 복합키) · 카피 규약 ·
KWCAG · 검증 명령 · 환경 주의점.

프로젝트 전체 메모리(제품 사실·아키텍처·현재 위치)는 저장소 루트의
**[`AGENTS.md`](../../AGENTS.md)** 다. 충돌하면 더 구체적인 `apps/web/AGENTS.md` 를 따른다.

## 왜 이렇게 뒀나

Claude 계열은 `CLAUDE.md` 를, Codex 계열은 `AGENTS.md` 를 자동으로 읽는다. 웹 지침이
`CLAUDE.md` 한 벌뿐이던 동안에는 다른 에이전트가 **"임의 재디자인 금지"·"자리표시자 금지"
같은 규칙을 모른 채** 웹을 고칠 수 있었다. 루트에서 같은 문제를 고친 것과 같은 방식으로,
내용은 `AGENTS.md` 한 곳에 두고 이 파일은 포인터로 남긴다.
