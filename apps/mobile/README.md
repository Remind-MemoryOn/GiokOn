# @giokon/mobile (placeholder)

어르신 대화 모바일 앱. **Phase D(M6)** 에서 Expo + React Native + NativeWind로 스캐폴드한다.

- 역할: 어르신 음성 대화 화면. 단, 기기는 **요양보호사 세션을 보유**(요양보호사가 로그인 → 어르신 선택 → 세션 시작 → 기기 전달).
- 공유: `@giokon/core`(도메인 로직), `@giokon/data`(Supabase·TanStack Query), `@giokon/theme`(디자인 토큰).
- 음성: Expo AV 녹음/재생. `SpeechProvider`는 Realtime 호환 심으로 설계.

현재는 워크스페이스 placeholder다.
